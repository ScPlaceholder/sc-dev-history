Just want to add some extra information on the mission.
The mission is called Data Grab and can be found in the Contract Manager under Personal>Mercenary. It is an unlawful mission and you will likely earn a CS4-5 if the Comm Array is up.
These missions are the first we feel cannot be soloed at the higher levels due to the need to be in two places at once. Other than the very easy and perhaps easy missions, we believe players will need the help of others to succeed.
A quick run-down of the difficulties:
Very Easy - Easy Data Grab
- Estimated mission Time = 38 mins
- Reward 30,000*
- Players suggested = 1
- Think of this like a repeatable tutorial. It can be soloed because the player is given markers to locate the overheating server and intrusion terminal. Players must upload 3 servers and only the currently uploading server will generate an intrusion. The reward is low due to the ease of the mission and it requiring only one player.
Easy - Quick Data Grab
- Estimated mission Time = 44 mins
- Reward 60,000*
- Players suggested = 2
- This mission become available after 1 Very Easy mission is completed. It removes the markers showing the overheating server and intrusion terminal leaving it to the player to monitor and locate, this makes soloing much more difficult. Players must upload 4 servers, but only the currently uploading server will generate an intrusion.
Medium	- Data Grab
- Estimated mission Time = 50 mins
- Reward 120,000*
- Players suggested = 3
- This mission become available when reaching the next rank of the Hired Muscle scope. Players must upload 5 servers, the uploading server plus a random one will generate an intrusion.
Hard - Heavy Data Grab
- Estimated mission Time = 56 mins
- Reward 300,000*
- Players suggested = 4
- Players must upload 6 servers, the uploading server plus a random two will generate an intrusion.
Very Hard - Massive Data Grab
Estimated mission Time = 62 mins
- Reward 500,000*
- Players suggested = 4
- Players must upload 7 servers, the uploading server plus a random three will generate an intrusion.
* As always, subject to change.

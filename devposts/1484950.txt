We do have contrails in the game already. Though not as spectacular as that video.
They were added when we introduced the 3 moons (and asteroid). Right now only when flying above Daymar will you see any contrails, since the other moons don't have enough atmosphere to show any contrails.
The implementation right now is quite simple. The only property we have access to, is pressure based on altitude and atmospheric composition. We don't have any weather simulation yet, so we can't go much further just yet.
Once the weather systems start to come online, we'll probably start using it for better contrails as well.

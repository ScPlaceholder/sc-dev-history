Greetings!
We are now testing character repair tool, a new system meant to replace the hard reset you once had assess to. The tool can be found on the PTU website here: https://ptu.cloudimperiumgames.com/account/reset. This should be a much lighter and more efficient system with less harsh consequences in-game.
What it should fix:
- Errors on PU load
- Missing mobiGlas
- Missing head
- Any other character issues
Won't fix:
- Ship and ASOP issues
In addition character repair won't reset your location, though it will reset your character loadout and require you to make a new character.  LTP is still applied, so reputation, income earned, and local inventory should be retained.
PLEASE USE THIS INSTEAD OF ACCOUNT COPY. Also, if you encounter a consistent issue drop it onto the Issue Council as well.
When you run into an issue you would normally recopy or reset for, please try character repair instead. When you get back into the game, let us know below any issues that remain unfixed.
Thanks for taking a look!

This is a very interesting question. First, we can use Quantum to balance the actual economy, by running it at real-time speed and feeding its data to the game, but also to test and validate future scenarios in advance by fast forwarding them in time to have an idea of their effects on the economy. Regarding the distribution curves, we can use directly the real-time price discovery data from the various entities (OHLC-Volume candles type for each product on the Bid and Ask side) from the Quantum simulation running in real-time. Another useful thing about Quantum is that it is a truly full simulation that is running, meaning that we can get data from each quanta individually if we wanted to. We can of course make NORM or GAMMA distributions out of that data, but we can tap into much greater detail if we want to. Each quanta live its own story in the simulation! Since there is so much happening in the simulation, the challenge is in finding the best way to get the relevant information from it. Aggregate type of information like distributions are interesting to get an overview, but another potentially even more interesting type of information is in investigating the behaviors of the Quanta. These behaviors can then help to feed the world with even greater details, like not only generating missions, but a whole backstory for the NPC that is fully synchronized with the economy.

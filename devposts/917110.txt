Quite a few players have been entering tickets to get help. :slightly_smiling_face: And lots of players have been helping each other here on the forums. The issue about using the google or torrent file is it may help short term, but there could be other network issues on the player side or our side that need to get checked out, fixed, etc.
If you do have a data.p4k issue, please do enter a ticket. You can add files to the ticket/email to help tech support investigate the issue faster.
Generate the DXDiag:
- Press the Windows key + R.
- Type "dxdiag" into the run prompt and click OK.
- Click "No" if dxdiag asks to check for digitally signed drivers.
- Wait for the bar to fill in the bottom left.
- Click Save all information and save the file to an easily accessible place, eg. your desktop.
- Attach the file to the ticket.
We also need the log for the Delta Launcher:
- Press the Windows key + R to bring up a Run dialog.
- Enter and run %appdata%\rsilauncher
- A folder view opens.
- Attach log.log to your ticket/email reply.
If you got a Crash Handler, send in those files:
- Press the Windows key + R to bring up a Run dialog.
- Type the following and click OK: %localappdata%\Star Citizen
- Please zip up the contents of the folder and attach the file. 
For a quick zip, select all of the files, right-click, and select Send to > Compressed (zip) folder. Attach that file to the ticket/email.
And investigations are underway to find the issue, get more logging, and pinpoint the issue to get fixes to the files/Launcher/Servers/etc.

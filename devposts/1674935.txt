All the network engineers on the game are familiar with the fundamentals across the engine, and this is a great resource as it makes tailoring the network code to suite the needs of the game much easier to understand and communicate if everyone is on the same page. This is becoming more and more paramount as we move to the server mesh architecture and the backend guys are going to need to support feature sets that absolutely require an understanding of how our objects in game are represented and modified by game code or physics.
I don't expect everyone to be a perfect programmer in all domains, but you are going to stand out for example as a network engineer if you're familiar with game engine programming, and vice versa a gameplay programmer will stand out if they have experience with networking.

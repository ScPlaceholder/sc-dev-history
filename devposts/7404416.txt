Error 6000 was not fixed. Error 6000 is the error code we used to display when the game crashed and sent an error code to the Launcher.
As the error behind the 6000 could be diverse we decided to change how we display the information.
We updated the message you will receive now. It will display clearly that this is a Game error and give you the error code from the game.
If you encounter a crash we request that you first report it in the Public Crash Handler that gets displayed after a crash.

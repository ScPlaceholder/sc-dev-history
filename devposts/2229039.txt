## Star Citizen Patch 3.6.0k
Alpha Patch 3.6.0k has been released to PTU and is now available to test!  Patch should now show: PTU-2054859.
It is strongly recommended that players delete their USER folder for the Public client after patching, particularly if you start encountering any odd character graphical issues or crash on loading. The USER folder can be found (in default installations) at C:\Program Files\Roberts Space Industries\StarCitizen\PTU.
Please monitor ptu test chat in spectrum for updates and testing instructions.
UPDATED USER.cfg settings:
r_displaySessionInfo = 1
The new setting will display a QR code that we can use to track down server information when looking at your bug reports and videos.  Then can be disabled by setting it to "0".
Note: This patch does not contain all of the intended features, which will be added iteratively to the notes as they become available. Additionally, some features may be implemented in a partial state and as such are not ready for testing.  When those features reach a playable state they will be detailed on the notes and added to the "Testing Focus".
Testing Focus
- Ship combat balance: Ship shields, missile damage, missile counter-measuring
- Flight: Acceleration control
- Head tracking
- P-72 Archimedes
- Ship component degradation
- Ship purchasing
- Pip accuracy and ship flight jitter
- Vanguard Warden and Hoplite
Known Issues
- Klim and Battaglia are unresponsive.
- The updated criminality and law system is only partially implemented, with some missing behavior and needed elements. We will not be describing or taking feedback on this topic just yet.
- Textures will display across the visor on some helmets.
- Depending on ship, sometimes when attempting to file an insurance claim the timer will either start with a long delay or never start at all.
- Players may get stuck at the bottom of the Vanguard's ramp. W/A: Jump off of the side of the ramp to avoid.
- There may be numerous collision and visual issues with the Vanguard.
- Hacking chips currently can't be stowed or retrieved after purchased.
- Hover mode has some impending changes/updates, we will not be taking feedback on it until those are complete.

## Bug Fixes
- Locked off the ability to ADS while prone rolling to prevent knock-on issues.
- FOIP facial animations should now be visible to other players.
- Blade should once again have thruster effects.
- Removed unintended UI elements from StarMap.
- Further fixes to prevent players being unable to respawn after dying far away from spawn point.
- Eslin at Levski should once again be on the job.
- Fixed bounce away effect when using free look while crouched and looking downward.
- Vehicle purchasing kiosk should now revert to splash screen if the player leaves while confirming purchase.
- The drug stash for seize and destroy missions on ArcCorp should now consistently appear.
- Area18 ATC should once again spawn ships.
- Interdiction AI ships should no longer despawn in front of the player.
- Further networking improvements to prevent ship rubberbanding, hitching, and stuttering.
Technical

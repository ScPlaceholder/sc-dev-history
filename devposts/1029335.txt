## Star Citizen Patch 3.1.0j
Alpha Patch 3.1.0j has been released to the PTU, and is now available to test! Patch should now show: PTU- 735941
It is strongly recommended that players delete their USER folder for the Public client after patching, particularly if you start encountering any odd character graphical issues or crash on loading. The USER folder can be found (in default installations) at C:\Program Files\Roberts Space Industries\StarCitizenPTU\LIVE.
Testing Focus
This patch is an early release to deliberately investigate server stability and slow down issues.  The team has an idea of what may be causing the issues you all observed over the weekend, but to test that we need to experiment with server settings in an environment with frequent player activity.  Login, attempt to connect, play in the PU has normal for now. We will fill in the notes as we go, so check back here often if you are curious about changes.
Want to help?  Hop on and hammer the servers!  We need as many players on as possible in the PU over the next few hours.  As always, your help is very much appreciated.
## Feature Updates
Universe
- Expanded several of the environmental missions.
Ships and Vehicles
- Increased the despawn time to allow players more time to get into the Reclaimer and take off.
Bug Fixes
- The salvage room of the Reclaimer should now have alert/damage state audio.
- The front lift of the Reclaimer should now have audio.
- The Avengers should no longer be missing their HUD.
- The MFDs should now work properly on the Gladiator.
- FPS weapons should now properly have their sights attached when equipped through the PMA.
- The canopy on the Hornet series should now close properly when entering the ship.
- Repairing a missing wing at CryAstro should now properly return the weapon as well.
- The HUD should now have countermeasures listed.
Technical
- Minor crash fixes.
Known bugs, issues, and work arounds (W/A):
- 40014 will cause a client crash. W/A: If this occurs, wait 10 minutes and relaunch.
- IFCS fixes are still pending.

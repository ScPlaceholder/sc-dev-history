Plans for the Ares haven't changed, we're still iterating but didn't progress as much as we wanted to.
Specifically for the Ion we tried out charge mechanics in different variants for 3.17 but we did not get to the point where we felt it was good enough to be shipped. One element that is missing here is UI feedback ... specifically for slow firing guns you need some feedback when the next shot is ready but fetching that info from the weapons is not that easy and requires a bit more coding (which competes against higher priority tasks).
Concerning the aim assists of the Ares we are considering bringing some of it back but we'll not do this until we ran enough balance tests to be confident that it doesn't hurt the balance as it did like in the initial 3.15 release (the Ares was way too effective against small agile targets which is not what she was built for). Tweaking aim assist numbers is not hard (the CLs have been ready for a while now) but finding the time to run isolated tests has been a bit problematic in the last months for multiple reasons. Among those a bit of team shuffling (see https://robertsspaceindustries.com/comm-link/transmission/18639-Roadmap-Roundup-April-27-2022) which in turn affected work schedules and priorities. Our current development priority is rather on overall combat development that benefits the whole game (with quite a few items from the last combat ISC, see https://youtu.be/5jyE46u8Qrw). We'll slot in more work for the Ares (and other weapon systems like the Singes) when we get the chance but it wouldn't be appropriate to promise release dates. But don't expect changes in the 3.17 cycle.

Note about deleting the whole appdata Launcher folder:
If folks want to clear the Launcher cache, I recommend the steps below. This keeps the Launcher log.log file without losing it. Capturing all of the game actions before and after the cache clear is very important if you need CIG support to troubleshoot.  Thanks!
The Launcher has a cache you can clear. Here's how:
- Press the Windows icon + R to open the Run command.
- Enter and run %appdata%\rsilauncher   A folder view opens.
- Select and delete the Cache and GPUCache folders. Clear the trash.
- Right-click on your Launcher icon and select Run as Administrator.

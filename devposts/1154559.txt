## Star Citizen Patch 3.1.4g
Alpha Patch 3.1.4g has been released and is now available!  Patch should now show: PTU-753197.
It is strongly recommended that players delete their USER folder for the Public client after patching, particularly if you start encountering any odd character graphical issues or crash on loading. The USER folder can be found (in default installations) at C:\Program Files\Roberts Space Industries\StarCitizenPTU\LIVE.
Testing Focus: Large ship planetary take off. ESP function in combat.
## Feature Updates
Ships and Vehicles
- Fixed an issue with IFCS rotation and further tuned ESP.
- Increased forward acceleration of the Reclaimer in atmosphere/gravity and upward acceleration when in landing orientation. Note: Its best to use landing orientation to stabilize and lift to a safe distance, then use the rear engines to push into orbit after raising the gear.
- Increased upward acceleration of the Caterpillar to aid in planetary lift offs.

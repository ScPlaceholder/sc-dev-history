Hey guys,
at this point I can't go into much detail yet as we have an ISC coming up. But to give you some pointers about the asked questions:
- All fixed weapon changes are independent of ESP.
- ESP will be improved for 3.10 ... the algorithm is the same but a lot of values were tweaked in focused PVP gameplay tests. 3.10 also adds customization options (for ships and turrets).
- We replaced the control maps for turrets. The "aim" and "look/view" axes for turrets are gone ... they now only have the "rotation" axes and they can be bound correctly.
- There were no dev resources available to work on the core input system, so the deadzone bug is likely still there.

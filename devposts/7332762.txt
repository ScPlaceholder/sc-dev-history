First, the play experience on the public environment sucks and that's not something I like to see so I'm sorry for that. Things like this can sometimes happen because the data trends and behavior that occur on the PTU might not match what happen on the public environment.
To answer your question, working in 3.24.2 and 4.0 are not mutually exclusive of each other. We've been working on fixing the issues with 3.24.2 and have deployed multiple hotfixes per day since the release of the patch to either address the issues that have clear solutions or have some limited servers with additional debug information to try and track down some of the more difficult to figure out problems.
When those hotfixes are deployed, we observe the effect of the fixes to see if it resulted in things getting better or worse. I have a graph that shows me how badly server crashes are affecting the player population over time and while it is trending better overall, it's still way worse than we want for the public environment and our work on stabilizing the play experience is still ongoing (I'm helping work on another hotfix as I'm typing this ).
The process of deploying a hotfix to the public environment and observing the effect that fixes have had can take a notable amount of time. Often times, something being fixed can cause a new problem to occur so we have to get debug data for those and send them to developers for those to be fixed as well. Gathering that debug info can sometimes take a few hours depending on how many new issues there are how big the debug files are. While all this is going on, developers are working on other things.

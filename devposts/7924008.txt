A thread about this started on reddit as well where some comparisons to WoW were made and I figured it might be useful for me to repost some of what I said there on Spectrum as well.
The comparable error that you'd run into in world of warcraft in this situation is "world server is down" because the server that is hosting the specific area of Star Citizen is having something go wrong with it ( usually a crash ).  From the  perspective of someone that used to work at Blizzard as a Game Master,  when something like this happened for WoW, players would put in GM  tickets for game masters to move their characters to different continents so they could get away from whatever continent had its server crashing. In Star Citizen, the fix that we have going in for this in  4.1.1 should allow for players to be able to keep playing without needing help from us because it should stow them after the first or second disconnection and allow them to join a different server.

Every two weeks, we accompany the Roadmap update with a brief explanatory note to give you insight into the decision-making that led to any changes. This is part of an effort to make our communications more transparent, more specific, and more insightful for all of you who help to make Star Citizen and Squadron 42 possible.
Just a reminder: The 1.0 column showcases features and content planned for inclusion in or before Star Citizen 1.0. This means you may not have to wait for the 1.0 release to experience them. As features/content in the 1.0 column become ready, they will migrate left into a point patch column for release.
Be sure to check back every two weeks for the latest updates.

## Notable Changes for April 9, 2025
## Release View
4.1
Space Combat Mission - Patrol
Adding a Patrol mission that takes the player through a series of patrol points. At each waypoint, players can run into a variety of objectives and encounters.
:scroll: The card has been set to Tentative.
Space Combat Mission - Ambush
Adding an Ambush mission that tasks players to set up a trap in an asteroid cluster and ambush high value target ships as they pass by.
:scroll: The card has been set to Tentative.
Space Combat Mission - UEE Training Missions
Adding a suite of UEE Training Missions that teach players about various ship combat scenarios, introducing new challenges as the player progresses.
:scroll: The card has been set to Tentative.
REDACTED Space Combat Mission
Adding a new REDACTED mission.
:scroll: The card has been set to Tentative.
Juvenile Valakkar
A new creature ready to challenge those who dare to cross its path.
:scroll: The card has been set to Released.
Argo ATLS GEO
Adding Argo’s ATLS GEO: A power suit dedicated to Mining, with practical augmentations including lasers, storage, and a new way to travel with jump packs.
:scroll: The card has been set to Released.
Drake Golem
Adding Drake's new Mining Starter Ship.
:scroll: The card has been set to Released.
Arena Commander: New Map - Astor's Clearing
Adding a Stanton settlement on microTech, available in Free Flight for exploration.
:scroll: The card has been set to Released.
Arena Commander: New Map - Crossroads of Crime
Adding the largest Arena Commander map so far, available in multiple game modes Free Flight, Tank Royale, Team Elimination, Elimination, Single Weapon Elimination, Gun Rush, Kill Collector
:scroll: The card has been set to Released.
Sandbox Activity - Align and Mine
A new open-ended activity blending on-foot exploration with aerial support, creating sandbox gameplay opportunities for daring teams.
:scroll: The card has been set to Released.
Mission Giver Location - Wikelo's Emporium
A specially designed location to host our latest mission giver, Wikelo, offering a new hub for players to engage in these opportunities.
:scroll: The card has been set to Released.
Mission Giver - Wikelo
A new mission giver enters the 'verse, bringing fresh opportunities for players to explore.
:scroll: The card has been set to Released.
Heavy Combat Armor "Antium"
A rugged and stylish new armor set tailored for brave adventurers facing new dangers.
:scroll: The card has been set to Released.
Hathor Mining Station
A large-scale mining laser facility operated by the Hathor Group.
:scroll: The card has been set to Released.
Hathor Ground Alignment Stations
Strategically placed Hathor-operated outposts providing key infrastructure and sandbox gameplay opportunities for planetary operations.
:scroll: The card has been set to Released.
VOLT AR "Parallax"
A powerful new weapon boasting a unique blend of characteristics, firepower, and tactical potential.
:scroll: The card has been set to Released.

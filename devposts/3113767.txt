3.9.1 did not change anything on the input system that would explain the behaviour that you describe. If you could describe the use case and how you setup your bindings and which periphery you use it would help us find the issue.
Btw, reinstalling the game is not really necessary, you can just wipe your User folder to reset the controls. If you suffer from changing USB device IDs I would recommend searching for tools that enforce a certain order. There is e.g. a tool called JoyIDs does just that and I am sure there are others as well.

FYI Raptor sent me his profile and I investigated what was going on. It seems some older smoothing code produces some odd artifacts when your profile has perfect dead zones ... which in this case is on the actor head and it makes it go crazy. I cannot fix that for 3.6 ... if you encounter that I suggest to avoid using perfect dead zones ... try using very low numbers but stay above 0 in the graph. For precision you can open each profile as an XML file and try editing your points there.
It's bugged up now ... but as I said try this work around ... any change on that particular piece of code won't get approved for 3.6 at this stage.

30000 is a symptom rather than a problem. It's what happens when the game client loses connectivity to the game server which can include both issues with the internet as well as server crashes so in that respect, it's never going to go away.
With that said, there are a few server crashes we do need to take care of in order for us to be in what I'd consider a passing grade for server stability. There's also always the potential that things may get worse because fixing certain aspects of gameplay can expose other stability problems (example being if we were to do something like fix a bug preventing AI from shooting, it might expose a server crash that happen when an AI shoots).

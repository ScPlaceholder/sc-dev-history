I’m not an expert in this specific area, but generally applications have little or no control over the page file, and as far as the game code is concerned everything is in “RAM” (as far as it knows/sees). Managing the page file is an OS level thing, and is used for cases where you are out of RAM or if there is data that hasn’t been touched for a long time so isn’t needed in RAM. So I’d say there’s nothing to worry about with SC “only” using 17GB.

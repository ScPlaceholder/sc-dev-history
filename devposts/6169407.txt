Hello Testers!
As part of the Master Modes preview game mode set we have an updated version of Vanduul Swarm exclusive to Master Modes. In this update, rather than a discreet set of waves that each have to be cleared in before beginning the next, there is now endless waves that spawn on a timer. With each wave, the balance of incoming damage (damage done to you) and outing damage (damage you do) will slowly shift out of your favor. Since the waves spawn on a timer, they will spawn regardless of if you have cleared the prior wave or not. This combination is intended to create an easy start but rapidly increasing scale of difficulty that tests any level of pilot skill.
Feedback we are specifically looking for:
- Difficulty and balance (please let us know how you would rate your own skill level as well, for reference)
- Client performance as the game progresses
Note: We have a dedicated thread for the master mode setup itself and this thread should be reserved for the game mode.
Let us know what you think! How far did you get? How challenging did you feel the mode was toward the end of your run versus the beginning? Looking forward to hearing from you!

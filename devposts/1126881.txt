## Star Citizen Patch 3.1.4c
Alpha Patch 3.1.4c has been released and is now available!  Patch should now show: PTU-749761.
It is strongly recommended that players delete their USER folder for the Public client after patching, particularly if you start encountering any odd character graphical issues or crash on loading. The USER folder can be found (in default installations) at C:\Program Files\Roberts Space Industries\StarCitizenPTU\LIVE.
Major Known Issues:
- If you strafe up from Gravlev in HOV and switch to SCM you may need to maintain altitude for a few moments to avoid it switching back to HOV.
Ships and Vehicles
- Improved transition between HOV and SCM modes for gravlev.
- Gravlev speed limit is now only limited by planar velocity.
- Improved ESP tuning.
## Bug Fixes
- Fixed a bug with boost/afterburner where boost was heavily over-performing on some ships.
- Fixed an issue with ESP that hindered aiming.

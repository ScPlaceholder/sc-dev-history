Maybe ¯\_(ツ)_/¯ Even if we were working on heatmap effects, I think we wouldn't want to write into SDFs as they are generic data. By adding more channels we would increase the cost of all SDFs just for the sake of adding some VFX specific data which might never get used by any other system. There are a lot of vehicles in the game and each unique vehicle type has its own set of SDF textures. Memory budget is already quite a challenge so we want to keep all generic data as small as possible whenever possible.
Having said that, damage map tech is procedural and dynamic. It's a 2d texture which maps onto a three dimensional objects so where you shoot you should see blast holes, glow etc. We had it in the game for quite a while (you know, all the burn and such when your wing gets shot off?). Also to clarify, this doesn't use SDFs.

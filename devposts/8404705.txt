This thread reminds me of an old technique that seems to have been lost to time. Back in the olden days, the original Doom supported multi-monitors using 3 separate cameras. Actually that's misleading. It used 3 separate computers (or more). You'd launch the game with networking using one machine as the host then when launching the other clients, you could specify a view rotational offset. So you'd have a screen looking forward, one looking 90 degrees to the right and another lookin 90 degrees to the left.
I loved that silly hack! :grin:

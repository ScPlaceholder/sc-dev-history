Hello! Larger game companies tend to have pretty specialized roles. Most of the devs that respond to questions here don't have access to our customer service tools and wouldn't be able to read the request. I used to have access to them, but that was something like 11 years ago back when we were smaller and I was doing a combination of QA and tech support work.
Without additional information, I wouldn't be able to comment on if the issue is a bug or a tech support issue so I don't want to rule out either of them. Especially since we just released a new patch and that's when we tend to see most account breaking bugs happen. To know for sure which of the two it might be, I'd need more information. For example: If it's a client crash, I'd need the digest ID which would allow me to look up which crash someone is running into. If it's a disconnection error, I'd need to know what the error number is. If it's something else like an infinite loading screen, that information is useful as well.
If it ends up not being an issue with the game, as a few people here have mentioned, the help desk is a good place to go for assistance. If you prefer forums instead of chat, we also have our community tech support forum where there are a lot of regulars that help people navigate various issues and get them back to playing. At this point, they're much better at it than I am because I haven't done any dedicated tech support work for years.

## Star Citizen Patch 3.1.4h
Alpha Patch 3.1.4h has been released and is now available!  Patch should now show: PTU-753198.
It is strongly recommended that players delete their USER folder for the Public client after patching, particularly if you start encountering any odd character graphical issues or crash on loading. The USER folder can be found (in default installations) at C:\Program Files\Roberts Space Industries\StarCitizenPTU\LIVE.
Testing Focus: Nox and Dragonfly Gravlev function.
Major Known Issues:
- The Dragonfly is currently consuming fuel in excess while traversing in Gravlev.  This is not intended.
## Feature Updates
Ships and Vehicles
- Adjustments Nox handling using Gravlev and minor adjustments to the Dragonfly.

The “VRAM Demoted” thing isn’t always a problem. We allocate memory in large chunks, typically around 250mb, and over time we shift memory between these chunks to use as few as possible. If the driver finds a chunk that isn’t being used (eg we reserve some mem for planets but it’s not used in outer space) then it may demote it to RAM without any performance impact. However when you run out of VRAM it’ll demote stuff that IS being used, and this means it needs to reupload to GPU and then immediately discard many of these chunks every single frame.. which is catastrophic For performance.
Btw we’d get identical behaviour on DX12, so those calling for this as a solution wouldn’t be saved. We’ve got some tech in progress which allows better re-use of the same VRAM via multiple systems, and should lower our peak VRAM requirement to help those experiencing issues.
For those with 6Gb or 8GB if it helps to run DX11 that’s fine (and should be improved by the above), but what we really need to diagnose is the issues stopping people running Vulkan at all.

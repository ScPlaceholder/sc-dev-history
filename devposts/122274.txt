Object container usage is being proliferated across the game, largely as a replacement for CryEngine prefabs, but also in places that prefabs would never have been used. For 3.0 we're moving to completely replace levels with the Mega Map, including in multiplayer, which works in part because of object containers. These are really important steps to setup the game so that object container streaming can work, which is going to be a hard requirement once the game world gets any bigger than it is now. These things have been in motion for some time now and it's really cool to see it starting to come together. Still lots of work to be done, but it's going to be really cool when object container streaming comes in.

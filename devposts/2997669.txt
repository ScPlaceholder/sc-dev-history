As the person who added spline jumps (https://www.youtube.com/watch?v=7Z38OUPkpRA) to the game, I can attest that not all quantum jumps are straight lines. We have not taken the time to generalize the code to work outside of jumping to surface locations, but it is doable if we dedicated some resources to it. For now it is more about priorities, but I can say that there is definitely ongoing discussions about where QT can go from here. QT is the main way to get around to our big locations in the game and therefor part of the main game loop. For that reason I'm confident it will continue to get refined as development progresses.

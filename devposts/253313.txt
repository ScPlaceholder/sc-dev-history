Short answer: sorry, unfortunately this probably won't work.
Long answer: Star Citizen is built on the Lumberyard codebase, but it hasn't been written as slot-in modules (not a great surprise, as Lumberyard didn't exist as Lumberyard when the project began). There are deep changes across the engine, and this includes alteration to the resource compiler and the formats it exports, so I'd be surprised if anything plays well with the off-the-shelf version of Lumberyard at all.

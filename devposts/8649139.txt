Things like this can be a bug with the game, or tech support issues. Hard to know which it is without troubleshooting it.
Easiest way to tell the difference between the two is to identify a computer that is able to log into the game ( physically going over a friends place, etc. ), and then log in with the account that's having issues. Knowing if it does or does not work on a computer where another account is able to log into the game is a useful piece of information to have when debugging things like this. Unfortunately, doing this is also not a great security practice since if that second computer is compromised with malware, it may cause account information to be compromised.
So barring that, usually step one for something like this is going to the tech support forum. A lot of the regulars there can help out with various problems. In order for this to be something that I forward to our developers to look at as a bug, we have to be sure that it's not a tech support problem. I can't convince a producer to take a developer off what they're working on without that.

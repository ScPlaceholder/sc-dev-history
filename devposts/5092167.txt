Hi all! The new event that is currently activating on the live servers is not intended. Our team is looking into a hotfix that would address the premature event start, and also the associated server crash.
While some are expecting the new event to kick off during Invictus Launch Week opening today, I'd like to clarify that this is not our plan. When we get closer to the event debuting properly on the live servers, we'll release more information, including a schedule.
UPDATE: We feel the issue is less impactful now, and you should be able to resume playing as normal. If the mission does unintentionally activate again and cause another server crash, that server will automatically respond by downloading our latest hotfix so that it doesn't happen again. This approach enables us to gracefully update all servers with the hotfix, rather than taking everything down which would impact the large number of players currently online.

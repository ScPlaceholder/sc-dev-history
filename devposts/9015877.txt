## Features & Gameplay
Gameplay
Abandoned Vehicle Cleanup
We have updated the new ship cleanup code for Grim Hex, Levski, and other social stations across Nyx. This new code adds ship cleanup rules that will cleanup ships in an abandoned state after 5 hours. This was already applied in the previous build for stations and major landing zones across Stanton and Pyro.
Ballistic Repeater Balance Pass
We have done a balance pass on Ballistic Repeater weapons to greatly reduce their damage.

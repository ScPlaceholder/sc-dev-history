I’d absolutely love a benchmark mode, but it’d likely take quite a bit of effort as the game is quite diverse so would need to cram in all the different scenarios and effects in a relatively short time. It’d probably need a bespoke level setting up for this purpose, so need at least an environment artist and cinematic artist for at least 2-3 weeks, plus game code support for a week or more to add it to the options menu, trigger it, and display relevant statistics.
We’ve talked about benchmarks internally many times, but usually in the context of general performance rather than just graphical performance, but this makes it much more complex as you need to trigger various game systems/logic to make it representative, and these tend to be less predictable and always evolving so it creates a lot of maintenance work.

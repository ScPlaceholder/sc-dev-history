The bad token is something the game client does when connections failed. It is a bug but it's a separate issue from the 16008.
The 16008 unfortunately has a number of causes that can both be gameplay bugs and tech support problems. The safest way to figure out which of these it is would be to contact our support team. They can temporarily change the account password and log into it to see if it's something wrong with the character data. If logging in works for them, that lets them know that it isn't the character data causing a problem and they can try exploring other solutions with you.

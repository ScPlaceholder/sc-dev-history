Yeah, I've never been a big fan of overriding the throttle level like we do in so many cases.  But if I understand the issue you're describing, I don't think that is a necessary consequence of overriding the throttle.  Currently, when we need the ship to continue moving at a given velocity, we set the throttle internally, which overrides the current throttle setting.  It returns to your actual throttle setting once you adjust it, indicating that you want to return to direct control.
Maybe the solution is to avoid doing this in a case where throttle is zero.  The purpose of this is usually to avoid remapping the throttle, causing an unexpected change in velocity.  But if your throttle is zero, this isn't an issue, because 0 always maps to 0, no matter what the maximum velocity is.   Any other value, the mapping changes based on the current maximum velocity.  So I will make a note to look at this.  It seems like a simple enough fix.

While it can sound appealing to just use the sample version unmodified, there are definitely trade-offs that they've made that affect things like responsiveness and stability that we wouldn't have been able to change easily, as well as errors in their code that we've fixed.
On top of that, there's quite a lot of stuff that's game dependent, for instance we want the surface lighting calculation to work similarly to the main lighting pass, so we have to have our own shader there so it can read shadows, mask out lights by area, etc.
Finally there's the performance aspect. We're in the optimization phase now and I'm chopping and rewriting all sorts of things to try to get the frame time down. That's a lot easier when it's all CIG code and we can move passes around, merge or split shaders, change internal formats and so on.

I don't know if a solution for this is possible, as the behavior itself is a bug, and if the system can correctly identify when the bug has occurred I'd expect it would be able to prevent the bug from occurring. It's like if we had a bug where sometimes firing your gun would kill you - that obviously sucks, but the task then is to fix the bug.

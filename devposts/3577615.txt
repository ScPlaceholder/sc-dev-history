Okay, I got the same at home. The problem with the Warthog is that it has two-way switches which "stick" in place. So when you turn of one of the switches they won't send another signal ... they simply stop sending. But in SC input system we only listen for changes not for states. We'd have to check always if the button has been released but that would require a deep change in input system ... e.g. you go in a ship while a switch is up, we would not be able to detect the up position atm. For three-way switches it is even harder. Certain sim games have even very specialized bindings for that along the lines of "if up flaps up, if down flaps full, else do flaps half".
TLDR we can add bespoke on/off bindings but it wouldn't help you in that case. :disappointed:

GPU crashes can absolutely be caused by the game itself. Most commonly this has been caused by cases where some part of the shader is supposed to loop N times, but the resource containing N has an incorrect value or has failed to bind for some reason (eg a resource that's still bound for writing will fail to bind for reading). If this makes the shader run for more than 2 seconds, we get a DEVICE_HUNG error like this one.
We've currently got some unexplained GPU crashes in our backlog but they're quite mysterious, such as a timeout that apparently happened in a very simple shader that just blends two images, so it may take some time for us to diagnose them.

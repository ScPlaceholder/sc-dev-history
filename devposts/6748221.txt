The slowdown with landing gear extended is on purpose, it is an IFCS safety feature. You will be able to turn that off once we have the IFCS config screen with the MFD rework (won't be in 3.23 but potentially the Q2 release). The same is true for the setting of the gravity compensation that is now also enabled by default in decoupled.
Just to be clear, the landing gear should not put the ship into coupled mode. If it does, then this is a bug.

A big thank you to everyone that helped contribute information to help hunt down this bug.
We identified and fixed a number of bugs that were causing the character to get into this state, and created a new database to be used for 3.0.1. Due to there being a new database, all accounts will behave as if it's their first time logging in.
An important thing that I feel is worth mentioning about game development is that sometimes different bugs can sometimes feel like the same issue because they result in a similar situation. If by chance, there are additional scenarios where someone is able to break their character to get it into this state again, we'll need to work work together to figure out what's going wrong much like we did for this issue so that we can figure out what is causing the problem.
Thanks again!

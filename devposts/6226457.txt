Greetings!
The new Master Modes flight system is now testable in three preview Arena Commander game modes.
- Master Modes: Duel
- Master Modes: Free Flight
- Master Modes: Vanduul Swarm (new)
This feedback thread is dedicated to the mode itself. A lot has changed with this mode even outside of the core flight tuning. For a full list of the changes associated with Master Modes, please check the relevant section in the patch notes.
There are several categories of feedback we are looking for, including:
- UI changes: Targeting bracket, PIPs, targeting UI (excluding mode designation, which is placeholder)
- Weapon changes: Ammo pool, autogimbal balance, capacitor tuning
- Flight tuning: Gladius handling, base SCM speed, afterburner mechanic, NAV mode usage
Master modes is shown here as an experimental mode on Arena Commander for the express purposes of collecting feedback, so your thoughts are invaluable to the teams.

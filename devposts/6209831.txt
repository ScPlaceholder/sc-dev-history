If you’re familiar with how to setup a user.cfg file then add this to it:
r_HDRDisplayDeviceLimits=0
This allows you to set any peak brightness value and ignores the limit provided by windows, however if you set it higher than your monitor actually supports (400 nits in your case) then you’ll get extremely ugly clipped bright areas.

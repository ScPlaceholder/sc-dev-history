At the point where IFCS gathers input, it is agnostic to the source of that input.  It comes in as a set of pitch/roll/yaw, strafe up/down, left/right, forward/back, and throttle levels.  The only place where there are any decisions made about how to process this data based on the source is in ESP where there are some differences when using one input source to pilot the ship but another input source to control the weapon aim.  Otherwise, everything is handled the same.

## Star Citizen Patch 3.1.4e
Alpha Patch 3.1.4e has been released and is now available!  Patch should now show: PTU-751263.
It is strongly recommended that players delete their USER folder for the Public client after patching, particularly if you start encountering any odd character graphical issues or crash on loading. The USER folder can be found (in default installations) at C:\Program Files\Roberts Space Industries\StarCitizenPTU\LIVE.
Major Known Issues:
- Decoupled is still not functioning correctly for boost and afterburner. W/A: Activate decouple with boost and afterburner on already.
- The Aegis Reclaimer is currently experiencing erratic behavior when taking off and landing.
- The Drake Caterpillar is currently having difficulty taking off from landing pads.
## Feature Updates
Ships and Vehicles
- Tuned transient motion to better match the tuning goals from the prior 3rd order motion, resulting in slightly less acceleration.
- Refactored and retuned ESP.
## Bug Fixes
- Recovering from a crash should no longer present the player with an empty ship list at ASOP terminals

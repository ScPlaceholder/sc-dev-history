Hello, Everyone!
Today we're rolling out another small update to the RSI Launcher that contains the following changes:
:rocket: NEW:
- Added a new warning type to the RSI Launcher.
- The RSI Launcher will now verify the OS Version before game installation.
- The RSI Launcher version will now be reported in crash reports.
:hammer_and_wrench: FIXED:
- Fixed an issue where some user agreements were not displaying correctly.
- Fixed an issue where the Authentication Token could become invalid.
- Fixed an issue where the game could be launched without valid credentials.
- Fixed an issue regarding geographic location not applying properly to User Agreements.
- Various Launcher Telemetry Fixes.

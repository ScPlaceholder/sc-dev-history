The tint system is what allows us to re-colour assets and swap out decals from a library of tint-palettes. It's used as part of the skin/paint system for vehicles and items, but is also used more extensively in environments to allow much greater re-use of assets and keep colour themes consistant across many assets. Each tint palette defines a primary, secondary and tertiary colour, gloss and specularity values for each, a set of 3 logo/decal masks with 3 associated colours, and a glass colour. Artists can set up hierarchies of tint-palettes such that a whole building can be assigned a hierarchical tint-palette that will correctly assign individual tint palettes to each separate element (e.g. exterior vs interior vs habs etc).
The GI system obviously needs to understand the colour of the walls to be able to correctly bounce light and for the most part it already does, but in some cases the system falls back to cube-maps (transparent objects and distant secondary rays). These cubemaps have geometry and materials baked in, and this is the part that doesn't currently support tints.

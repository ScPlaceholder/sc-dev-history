Hello everyone!
With the imminent release of Star Citizen Alpha 3.13.0, we have brought the New Issue Council into its next phase of testing. As of today, the new Issue Council will be directly accessible from the primary RSI Website. While the development of this improved tool continues, we felt that the overall utility of this new version of the IC would vastly bolster the bug triage and feedback loop between backers and developers as we continue to work on 3.13 and beyond.
For more information about using this version of the Issue Council, the guide on the RSI Knowledge base has been updated and can be found here:
https://support.robertsspaceindustries.com/hc/en-us/articles/115009643527-Bug-Reports-Using-the-Issue-Council
Bugs encountered with the new Issue Council can be reported in the Issue Council project and should access become limited, please feel free to report major issues in this thread.
Thank you to everyone who has contributed to testing this new Issue Council, the teams working on this project couldn’t be happier with the results so far.
Finally, be on the lookout for a full comm-link going over the new Issue Council in far greater detail in the weeks to come!

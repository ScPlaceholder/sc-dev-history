Today we're releasing RSI Launcher version 1.6.9.
The main feature for the Launcher 1.6.9 is a LIVE STATUS link. With this link, you can access the status page https://status.robertsspaceindustries.com/.
The link color evolves depending on the status page state. For example: if the link is red, one of the three environments, Platform, Persistent Universe, or Arena Commander is undergoing a major outage.
## :gear: CHANGED:
LIVE STATUS link gives access to the status page and inform if we have an ongoing incident.
If you find any bugs on RSI launcher 1.6.9 please include your log.log* file in your Issue Council report using the "RSI Launcher 1.6.9" category.
* The log.log file can be found under C:\Users\<username>\AppData\Roaming\rsirclauncher\logs

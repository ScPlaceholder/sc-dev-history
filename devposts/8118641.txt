I can’t provide a specific distance for the rendering of grass meshes until we release Genesis/V5 and it’s fully optimised. However a core pillar of this tech is avoid any popping or colour changes on approach, so when the grass mesh disappears it will be replaced by textures with a similar appearance, and beyond that you’ll still see the same green patches of grass from orbit. This is not a problem most games need to solve, and has been a significant challenge.

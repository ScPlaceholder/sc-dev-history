Hello everyone,
Today, we are excited to share the RSI Launcher 2.0.2 with everyone.
RSI Launcher 2.0.2 can be found here:
https://install.robertsspaceindustries.com/rel/2/RSI%20Launcher-Setup-2.0.2.exe
The focus of this version is to add the Launcher debug tools that will allow you to clear the Launcher cache (Launcher store.json in AppData\Roaming\rsirclauncher).
2.0.2 will also give a quick access to your logs, to the new uninstall feature, and a tutorial for new users of the RSI Launcher.
Please try out these features and let us know what you think! Your feedback is crucial in helping us make the Launcher the best it can be.
## :hammer_and_wrench: New feature:
- Tutorial for new Launcher users. The tutorial can be found under the main menu when clicking on discover.
- Debug tools: Allow the user to clear launcher cache and a direct access to the logs.
- Uninstall
## :wrench: Fixed Issues:
- Fixed access for gifted game packages
- Set minimum size on Launcher first opening
- Spamming play/pause button
## :bug: Known issues:
- A 3001/3005 error may occur when downloading the Base P4K. Verify to fix.
- Launcher is not able to create the StarCitizen/Live folders for some users. Error 2000 or Error 5008 or Error 5010. Please try creating the folder manually and run the Launcher as administrator.
- Users can reset the Launcher's state while the game is running using shortcuts.
- CPU usage is hight when the background video is running.
- For some users the background video stops or flickers.

Strong possibility that the game servers this occurs in are suffering performance issues when MobiGlas is behaving this way and there's a number of other systems that don't work well ( or at all ) when the server is having issues. The approach that we take with those is to gather performance data on the server and provide it to our programmers so they can look through the information and see if there's any obvious areas that need to be fixed. It's also incredibly useful when QA is able to identify steps for how to get performance issues to occur because some of them aren't problems that performance data would help with. For example, if two ships spawn inside of each other and angrily vibrate, it might look like physics is causing performance to degrade when in reality, the ships shouldn't be inside each other.

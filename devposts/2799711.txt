The QR code contains a timestamp, a unique session id for your client (which is randomly generated each time you restart it) and another session id for the server (again randomly generated when it starts up). These session ids are added to the telemetry data sent to our analytics backend so when a backer reports an issue with a video or a screenshot we can use the QR code to quickly find the telemetry data relevant to that particular client and server. This can sometimes help us understand what might be causing an issue or give us an indication of what reproduction steps to try.

A 30000/20000 disconnect happens when your client doesn't receive any network traffic from the server for a while and the connection times-out. You will see this anytime something causes the network connection to be interrupted in a non-recoverable manner. This type of disconnection can be caused by a failure at any point along the route across the internet, so it's not always possible to determine exactly where the failure was. That said, the most common cause of these disconnections are when the server crashes, and your client is left wondering why it's not getting traffic anymore.
If you see this type of disconnection, immediately try opening a few different websites in your browser. If you can connect to them ok, that probably rules out problems with your local network, router and ISP. To most users, server crashes appear to happen randomly (unless you're the one doing something that hits a bug and causes the server to crash, and then keep doing it). So if the 30000 happens randomly during loading or gameplay, and your internet connection is still good, then it's probably a server crash. However, if the 30000 always happens at the same point, then something else is going on, in which case please make sure to report it to the issue council.

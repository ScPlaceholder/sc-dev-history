Honestly I do not know right now. In the past there was a bit of an internal discussion concerning what crew members should have access to remote turrets. There are basically two POVs here:
- Remote turret should never be possible from a pilot / driver seat as this discourages multi-crew.
- Remote turrets should always be possible from a pilot / driver seat as this makes it easier to fully use the vehicle solo.
Same goes with things like availability of external cameras, camera-based aiming of turrets, etc.
Frankly, not sure what we will going to end up with, right now we have a mix of approaches as the behavior is defined in the data. Since ACFT makes huge strides forward with AC and game modes we might as well just turn that turret behavior into a game mode option in the future. Then it would be easy to define e.g. hardcore vs more arcade style game modes. So all in all it is not trivial to answer right now. I'll bring it up in our discussions with ACFT.

Which controls are you using to zoom out here? If you're using f4+arrow keys/pgup/pgdown then that actually moves the point the camera is looking at rather than moving away from the original point, so the camera will now rotate around a different position. You can use f4+scroll wheel to move away from the original point instead and it should rotate around the ship as expected (the clipping issue still needs to be fixed though, we'll look into that).

For 3.20.0, we have made a number of updates to the mechanics of cargo trading to support the functionality of the Hull C. For the Hull C :
- Purchase cargo at the commodity kiosk (admin for stations)
- Spawn the ship and then request a cargo loading stations via ATC (separate cargo contact)
- Navigate the Hull C into the indicated zone and wait for the cargo to load
See patch notes for a more detailed description. In addition, cargo boxes have been updated to include a wide range of SCU sizes that are auto-selected based on the size of the cargo area as well as the loading space. This change should make transfers ship to ship much quicker and less resource intensive.
Take the Hull C out and do some cargo run stations to station, where some new commodities have been added specifically to test out Hull C bulk trades. Give other cargo vehicles a run as well trying out the new box sizes. Let us know what you think!

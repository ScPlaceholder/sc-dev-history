@Strubbelvader, yeah I understand the worries about input complexity and I would agree that a gamepad or HOTAS setups like the TM HotasX (which I have used a lot in the past) do not have enough buttons to completely support the game atm. I'm gonna mention a couple of things we have planned for later down the line:
1) At some point we wanna take the time to allow creating custom modifier buttons for sticks. Atm the existing modifiers are hard coded but it doesn't need to stay that way. It requires some time to do it and I cannot say when it will happen but it is tasked up somewhere.
2) The upcoming operator modes (with the Missile Operator Mode being the first one) actually allows a lot of optimization in terms of input configs. Since some of those operators will be exclusive to each other (using guns and missiles on the same seat is not allowed at the same time) it frees up a lot of buttons (e.g. weapon groups, gimbal modes, swapping lead / lag pips are all not used during M.O.M.) ... so certain functions can be collapsed to the same buttons on the sticks.
3) In general our default bindings for sticks are hopelessly outdated. We'll soon start to update and including profiles that closer match the current range of available sticks.
4) We're thinking about to more combined keys. E.g. for the capacitor controls you'll have the default needed bindings but we'll also add a couple of "combined" bindings that have a different function based on whether you do a tap or long press. Similar combinations can also be created for other functions on a case by case basis. As always I am open to suggestions here. :slightly_smiling_face:
I hope that somewhat answers the statements. We worry about input complexity and doing our part to improve on that. However I do not think it's realistic to expect a true parity here. A stick with 90 buttons of course offers a lot more flexibility than one with only 12.

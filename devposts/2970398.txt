Another long planned feature. There's work across several parts of the game that would land on several teams in order to get this working. We've taken steps over time to make it more possible. Eor example some of the recent service work they've done on the backend team is engineered anticipating multiple characters despite legacy code assuming a 1 to 1 mapping from account to character. The changes for global persistence and SOCS also are a big leap forward for us to be prepared for this since we have generalized a lot of the persistence behavior that previously was very account/character specific. But there's still a lot of code assuming this single account/character mapping, especially when querying/writing persistent data from game code, not to mention we need to update the character customizer to allow for managing multiple characters, and also any other services that may still need updating. So we're not there yet, but we've made some really good progress and I think after we've gotten through this big push for global persistence this will be one of the things in the discussions for what to tackle next regarding persistence.

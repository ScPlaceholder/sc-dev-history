To be clear, I'm not really trying to tear any other programmers or languages down, just laying out how we do things in the games industry. Python is great for throwing together some scripts, and even internally we'll use it to say convert some data over after a code change touches a bunch of assets for example. But Python never touches the actual game itself which is the key part.

SGGT is pretty different from Evocati. Think of it more like the playtest labs other studios run. The idea isn’t open feedback like we usually do on Spectrum threads. Spectrum is great for getting a feel for overall community sentiment, but when it comes to more divisive features (and ... let's say ... the somewhat challenging dynamics of public internet discourse), we can't always rely on it with full confidence.
That’s where SGGT comes in. The goal is to make sure that feedback is both solid and protected from bias and social engineering, so we can ultimately make better design decisions. SGGT runs narrow, targeted gameplay tests with carefully selected groups of players. These groups can be very specific, such as "PVP Pirates", "Lone PVE pilots" or "Cargo Haulers" or "Space Moms/Dads". Because we define the groups, their composition and sizes, we can easily run A/B comparisons or compare results between different playstyles. E.g. we can test with first-time players how effective our tutorials are or check if a change on the weapon systems is accepted by both PVE and PVP pilots. Coupled with an NDA that gives us a much higher confidence in the feedback, specifically for divisive features.
A test usually only runs for a few days. Once it’s done, access gets revoked, surveys (or whatever format we’re using) go out, and then maybe a new batch of players comes in. There won’t be a priority system or application process, because the groups are defined by the test itself.
So all in all it's really a very different type of testing compared to Evocati. SGGT and Evocati players might overlap at times but it is entirely dependent on the test itself.
I hope that clears up the difference. :slightly_smiling_face:

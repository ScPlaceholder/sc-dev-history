Today, we are excited to share the RSI Launcher 2.0.0 (Beta) with all backers!
Our beloved Legacy Launcher, which has been a trusted companion for our community, required a significant UI overhaul to keep up with the evolving goals of Cloud Imperium Games. With this in mind, we are excited to present Launcher 2.0.0 (Beta) – a fresh, modernized UI designed to enhance your experience. We invite you to download it and explore the new features of the Launcher.
The new Launcher will be in continuous development and this initial launch provides us a strong foundation for the future. You will begin to see new features coming your way, which will range from simple quality-of-life improvements to brand-new functionalities. More information about new and upcoming features can be found here:
https://robertsspaceindustries.com/comm-link/transmission/19818-Introducing-The-RSI-Launcher-20
## Why Beta?
This is a beta version because we continue to support the Legacy Launcher 1.6.10. At some point in the near future, we will decommission RSI Launcher 1.6.10 and the 2.0.0 will become our only Launcher.
## Heads up!
The new Launcher will not know where you downloaded your game. Please, update your Game Library path if your game is already downloaded somewhere else than the default path.

## Known issues:
- Updating the Launcher will reset your game location. If your game is not downloaded in the default path please update it in the game settings.
- A 3001 error may occur when downloading the Base P4K. Use Verify to fix.
- Launcher is not able to create the StarCitizen/Live Folders for some users.
- Users can reset the state of the Launcher while the game is running using a shortcut.
This is the beginning of the Launcher 2.0.0 adventure, we cannot wait to hear about your experiences using it!
## Shortcuts:
ctrl + r: reload the app
ctrl + shift + r: restart the app
ctrl + alt + shift + r: reset the app

A single report should, for the most part, record all contributions across all versions that the issue was encountered in. A new report should not be created for each version - you can select the precise version when making your contribution.
The only exception to that is if a given version is under active NDA. A new report should be created in that instance, with said report being merged once the NDA is lifted.
We absolutely agree that the duplicate check section would benefit from improvements to the relevancy of the reports shown, and are investigating that. Also, we would like to allow you to indicate that an issue that you reported/contributed to in an earlier version is still ongoing in the current version, so we are looking into that, too.

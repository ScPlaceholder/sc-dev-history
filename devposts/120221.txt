To echo what @M-A-D-A-O mentioned in his reply, one of the things that I've been learning since starting this is that we are constantly learning crazy new things about space and it felt like we would create an expectation that we'd need to stay current as more and more information is being discovered, which could potentially cause complications, i.e. if initial observations about a star turned out to be wrong and we had cited that specific star in the game, it feels like it would be a debate about updating the in-game version to correctly mirror the real one. It just seemed cleaner to just establish our own set of stars, so we can control the character/feel of the system without having to worry about real world comparisons.

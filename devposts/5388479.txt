Most teams had already written the code for most of their persisted features to use serialized variables. Where previous versions of persistence only persisted some of the serialized variables of some entities, PES persists all serialized variables for all entities. So most of what persisted before, and a lot more besides, will persist with PES without any extra effort. However some features used other APIs that have had to be replaced so those teams had to work at updating their features to be ready for PES.

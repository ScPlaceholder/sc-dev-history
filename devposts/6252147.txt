Great question! I've been asked this question quite a lot so I've come up with some general recommendations. Bear in mind my recommendations are more from a gameplay programming perspective, but I think even if you're interested in other parts of game dev like graphics it is still a good starting point.
///////////////////////////////////////////////////
Programmer Recommends
The main language used in large AAA gamedev is C++ (but I also recommend spending time in pure C as well). On occasion you'll need to work in a scripting language like Lua, but once you are well versed in a low level language it's much easier to pick up a scripting language. In my experience interviewing and working with people who did it the other way around it can be a much more difficult experience for them.
Below are a list of resources I think can be highly valuable on the often confusing journey of becoming a gameplay programmer. In addition you should grab an engine (I recommend Unreal) and just make things. I think a path to success will combine leveraging resources like below with an ongoing effort to work on small games. You can build a portfolio as well as develop your skills by solving many smaller problems. I also encourage you to meet other game devs, programmers and otherwise, and collaborate or just share your joy and experience making games. You'll learn a lot about games in general. Everything from how artists get their work into the pipeline to how the animators create their state machines is going to make you a better gamedev, and it's also just fun!
///////////////////////////////////////////////////
3D Math Primer for Graphics and Game Development
This is an excellent book by a mathematician and programmer from Valve that covers the most used math in gamedev from first principles and importantly with code examples. I recommend this book to literally everyone constantly haha
Free Online version:
https://gamemath.com/book/intro.html
Physical Copy:
https://www.amazon.com/Math-Primer-Graphics-Game-Development/dp/1568817231
///////////////////////////////////////////////////
Freya Holmer's youtube channel is also a great resource for some more applied 3D math for games:
https://www.youtube.com/@Acegikmo/videos
///////////////////////////////////////////////////
Handmade Hero is a very long running series by former RAD Tools programmer Casey Muratori where he programs a game (and literally everything else for it) entirely from scratch. Very long form but a good thing to pick and choose some videos on an extremely wide range of topics. I think as useful to hear how Casey reasons about problems as it is useful to see any particular solution.
https://www.youtube.com/@MollyRocket/videos
///////////////////////////////////////////////////
The Data Oriented Design online book is a great resource for building a framework for how to approach performance oriented programming. There's lots of resources for approaches using various abstractions such as OOP, but it's harder to come across good resources that start with centering performance first, so this is a great resource to that end.
https://www.dataorienteddesign.com/dodmain/
///////////////////////////////////////////////////
The C Book is a classic book for low level programming fundamentals.
https://publications.gbdirect.co.uk/c_book/
///////////////////////////////////////////////////
Effective C++ and Modern Effective C++ books by Scott Meyers are classic sources for learning how to weild the unending language that is C++.
https://www.amazon.com/Effective-Specific-Improve-Programs-Designs/dp/0321334876
https://www.amazon.com/Effective-Modern-Specific-Ways-Improve/dp/1491903996/

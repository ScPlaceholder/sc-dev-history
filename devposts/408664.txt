10002 happens when the game client isn't able to connect to the authentication services. It does look like we had a sizable amount of people in the USA region disconnect around the time that you made this post so I can check on things and see what happened. There's a number of things that could have caused it from something wrong with the game, something wrong on Amazon's side, something wrong with one of the internet hops that the server traffic has to go through, to something being caused by the Hurricane that is currently off the coast. I'd suggest doing a DNS flush because in the event that something happened to one of our authentication servers, your computer or router may have a dns cached address that is no longer valid.
To put some of the theories to rest:
- No this is not a memory leak. Memory usage for 2.6.3 is pretty good. I also restart all the empty servers when I get to work in the morning which doubly prevents them from running out of memory.
- If someone ever experiences an issue where they disconnect and the UI no longer gives them the option to join the PU, that's a cleanup issue that negatively affects the game UI, not the game servers. Essentially what happens is that it doesn't properly clean up when someone is forcefully disconnected so it thinks they're still in the map which causes the UI to break.
- While there was a notable number of players disconnected from the US region when this happened, there continue to still be US players connected to and playing the Crusader map. It only takes about 5 minutes for a new crusader to come back in the event that one of them crashes (granted that will probably change in the future as the map gets bigger)
Update:
All of our authentication servers are still up and running and there were no players disconnected due to game server crashes at this time. However, all of our USA authentication servers suffered a loss of player connections and it looks like this was caused by a networking issue that occurred outside of our game environment (so might have been caused by an Amazon network issue or complications caused by the hurricane).

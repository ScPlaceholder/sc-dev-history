We submitted the changes to 7845639. Given that it changes existing rotation space be prepared that the Vjoy movement will feel a bit different. Also the movement space on your HUD is now a square instead of a circle so it translates better to your mouse movements. If you want to stay with the legacy implementation you can still use it by setting v_vjoyType to 0 (via console or cfg file, default is 2). Please give it a go when the next PTU build comes in.

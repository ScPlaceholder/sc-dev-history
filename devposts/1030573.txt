## Star Citizen Patch 3.1.0k
Alpha Patch 3.1.0k has been released to the PTU, and is now available to test!  Patch should now show: PTU-736577
It is strongly recommended that players delete their USER folder for the Public client after patching, particularly if you start encountering any odd character graphical issues or crash on loading. The USER folder can be found (in default installations) at C:\Program Files\Roberts Space Industries\StarCitizenPTU\LIVE.
NOTE:  If Star Citizen "hangs", please wait at least 2 minutes for the crash handler to detect.  A hang is when the Star Citizen window whites out and you see the windows spin wheel indicating the program is not responding. In addition, all players start with a service beacon rating of 0, please set the initial requests to "any".

For now, there's only one route. We have discussed a lot how we could make them more dynamic with hazards or alternative pathways that open up. Logically, there would only be one core route out per location but we would like to, eventually, introduce elements into that core route that would change over time or circumstance. Also I'd fully expect that no two prisons would have the same means of escape.
Though it is static for now it most certainly isn't easy. Also, even if you do manage to get out you are still on Aberdeen, which is no picnic in itself.

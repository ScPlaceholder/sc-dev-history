Hi, I got some bad news on this topic:
We decided to NOT add a "stop gap" VJoy for 3.9. The UI department would need to build it using the legacy tech which is extremely time intense. I'm aware that "just adding a dot" sounds like a small thing but we seriously would be looking at several days of work to get this set up properly and it would also be entirely throw away work. So instead we decided to stay with the original plan to add the VJoy back (and then built on the new UI tech) in the release after 3.9. I know that some people will be unhappy about this ... but it is a far better use our limited time resources.
Sorry about this :disappointed:
On a more positive note, 3.9 will have a couple of smaller changes which prepare for the later HUD work. Among those are the ability to tweak the range of the VJoy/Aiming Reticle in pitch and yaw in the user options and we're also re-adding the ability to use head tracking to gimbal your weapons.

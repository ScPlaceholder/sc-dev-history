Internally, there's nothing keeping us from doing something like this.  IFCS is purely 6DOF acceleration control.  It provides control system options for pure acceleration control, velocity control or positional control on each linear or rotational axis.  The flight modes you use are high level modes that interpret player input and then generate accelerations on each axis through one of the 3 control modes (accel, vel, pos).  So there's no favoring one high level control mode over any other.  It's entirely up to the designers to decide how they want the control system to translate input into ship motion.  I know we could do a better job supporting some pretty basic control setups (dual sticks, for example).  All I can say is, just keep speaking up about it.  Once IFCS starts to settle in, hopefully we'll have time to explore some other control modes.  Or even to provide some kind of interface for custom control.

We know about any 30000 that occurs with regards to it being a server crash so you're definitely correct there.  Plus if everyone in the server is disconnected there's a relatively good chance that's a crash, as the other possibilities that could cause something like that are quite rare. We have analytics that show us how often each different kind of server crash happens so we're able to easily identify the ones that happen the most often. The problem with using that kind of a model is it will miss-prioritize things based on their frequency which can cause specific parts of the player population to encounter crashes more than others if there are less people playing the parts of the game they like. I'm well aware of the issues we have in the data model we're using for prioritization of server crashes but the same people that would help make the analytics more accurate are also working on programming game systems so for the time being, I make due with the data I have.

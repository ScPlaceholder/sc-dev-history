Boost is a "bool" type, meaning it is either on or off. If we add it to an axis command it will wrongly communicate that there is a thing such as "half-boost". With the current bindings UI I'd rather not go down this route ... looking further in the future we might be able to tell on the bindings themselves if they for are analog vs digital functions. But right now it's not the time for it sadly, it would be a topic for after we got a new bindings screen that uses building blocks.
That said, we could think about turning it to an axis command to give a pilot greater control about boost ... but that would be a different discussion.

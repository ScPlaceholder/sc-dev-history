@bparry-cig is on the money about how Light Imposters work, but I can go into a little more detail if you'd like to know a bit more of the technical bits. Also a fun little factoid for you guys: If you pixel-peep in the sky, you might be able to see some other planets where they actually are in the game world! They actually use the Light Imposters!
We have a simple pass on CPU that collects all the lights the player can see that are really small on screen and collect them all into a single pass for the GPU. If the light is animated we update its parameters, if it's static we actually cache those values to speed up collecting them immensely.
Then on GPU we have all the lights first render some depth values (this is why the lights still get depth of field), then we render all the Light Imposters. Because the data they store is simple we render ~1000+ per draw. They start appearing at 6x6 pixels, but are mostly invisible until they get to 2x2 pixels, where they become fully visible. How both of these are rendered is just some very simple shader trickery to make a circle that fades to a 2x2 squares. This way you end up with a smooth fade in over long distances. We also do a similar fade out whenever a light is far enough that it shouldn't be visible anymore (because of how small it is, or just to save engine resources).
Also really glad people seem to like them, the response has been inspiring!

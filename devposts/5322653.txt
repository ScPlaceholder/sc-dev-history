Hey all! This is a question we typically answer in the IAE FAQ yearly, as it's a common one! (https://robertsspaceindustries.com/spectrum/community/SC/forum/3/thread/intergalactic-aerospace-expo-2951-faq-visit-us-on-)
If a ship has a variant that is an entirely new hull/model, as some have mentioned here, it wouldn't be eligible. The Cutlass and the Hercules are examples of this.
If a ship has variants that are intended to be modules in the future, where the internals are what's changing but not the hull itself, then it would be compatible with the winning paint. The 600i and the MPUV last year had the BIS paint functional for all variants.
Since the only difference between the two Pisces are the hardpoints, both would have the new paint be functional.

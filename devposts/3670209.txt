Yeah, the decoy launchers are burst weapons ... the reason is that the countermeasures have a very short burn time so in order to use the additive effect of them they need to be thrown out in rapid succession. You can single release the CMs but the fire rate will be a lot slower that way.
It is very likely we will do some more changes with the release of the missile operator mode next year ... but for now we'd like to see how players actually use them and then we will adapt things accordingly.

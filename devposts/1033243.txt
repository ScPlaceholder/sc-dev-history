## Star Citizen Patch 3.1.0l
Alpha Patch 3.1.0l has been released to the PTU, and is now available to test!  Patch should now show: PTU- 737437. It is strongly recommended that players delete their USER folder for the Public client after patching, particularly if you start encountering any odd character graphical issues or crash on loading. The USER folder can be found (in default installations) at C:\Program Files\Roberts Space Industries\StarCitizenPTU\LIVE.
Note: If Star Citizen hangs please wait 2 minutes for the crash handler to detect.
Testing Focus
Universe - Service Beacons and server stress testing.
Ships - Reclaimer and Terrapin
## New Features
Universe
- AI pilots interdicting players can now carry interdiction dampening devices.  Those ships must be destroyed before the player can QT away and will be marked.
UI
- Players will have a HUD indication for quantum suppression.

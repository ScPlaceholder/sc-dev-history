For 3.15 we started updating a couple of default profiles and we would like to know if they load / work as intended. The following profiles have been updated or added:
- Thrustmaster Warthog HOTAS
- Thrustmaster Warthog HOTAS + pedals
- Thrustmaster T16000m
- Thrustmaster T16000m Duals
- Thrustmaster T16000m + TWCS Throttle
- Thrustmaster T.Flight Hotas X
- VKB Gladiator NXT Premium Duals
- VKB SCG Premium Duals
We know these might not match the exact control scheme you are used to but we think these are good starting points for those new to the devices, for now we are mostly checking if there are any issues loading and if they function as intended. Attached to this post you will find some dev pictures of the button assignments. Please let us know what you think about the assignments, if you find any issues or if you have any trouble loading them.
As you might know we have an ongoing issue that Windows often mixes up the order of input devices and especially for dual stick configurations we do not have a reliable way to separate the left stick from the right one. In each profile the device order goes from "right hand" to "left hand" to "pedals". Also make sure you do not copy previous bindings over!
Thanks for checking these out!

## Star Citizen Patch 3.1.0n
Alpha Patch 3.1.0n has been released to the PTU, and is now available to test!  Patch should now show: PTU-738784
It is strongly recommended that players delete their USER folder for the Public client after patching, particularly if you start encountering any odd character graphical issues or crash on loading. The USER folder can be found (in default installations) at C:\Program Files\Roberts Space Industries\StarCitizenPTU\LIVE.
New Known Issues:
- The graphical corruption issue persists in this build.
Testing Focus
Universe - Service Beacons and server stress testing.
Ships - Reclaimer and Terrapin
## Feature Updates
Ships and Vehicles
- Reorganized the default MFD screen layout on the Reliant.
- The forward, single person lift on the Reclaimer can no longer be triggered in zero-g or when the landing gear is raised.
- Temporarily disabled the top turret on the Reclaimer pending future fixes.
Star Marine
- Temporarily disabled Star Marine in game loadout swapping pending future fixes.
- Updated the backdrop of the Star Marine loadout manager.
Bug Fixes
- The cargo elevator of the Reclaimer should no longer detach from the ship.
- Players should be placed in proper chat channels when loading into the universe.
- Players who create beacons should now have their name displayed properly on their MobiGlas.
- Ship debris should now be eventually cleaned up.
- Vehicle destroyed bonus should now be correctly awarded for destroying the pirate Cutlass in Pirate Swarm.
- The ship selection menu in Arena Commander should no longer be labeled as "Contact List".
- Arena Commander multiplayer modes should now begin properly.
- Re-initializing quantum travel after interdiction should no longer result in loss of engine function.
- Getting destroyed by another player's self destruct should no longer apply a suicide respawn penalty.
- The Scorpion should now be properly attributed to the Gladius.
- The helmet part of the Star Marine loadout manager should no longer be over-exposed.
- Players should no longer become stuck on the ladder near capture point A at Echo 11 in Star Marine.
- The rear portion of the Reclaimer should no longer clip out of the VMA preview screen.
- Non-outlaw and marine items should no longer be available for use in Star Marine team games.
Technical
- Performance tweak for Port Olisar.
- Fixed 15 crashes.
- Performance optimization for getting stuck at single digit FPS.
Known bugs, issues, and work arounds (W/A):
- 40014 will cause a client crash. W/A: If this occurs, wait 10 minutes and relaunch.
- IFCS fixes are still pending.

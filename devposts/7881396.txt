So now I won't be able to equip both a pistol and a medgun
There is a multi-tool attachment that has healing capabilities on, you are still able to equip a pistol and a medical tool
That and you have access to medpens which can heal you, your character should not be able to do everything without trade offs
The medgun is incredibly powerful and has zero downsides to equipping previously making it a 100% requirement in a loadout for any serious player
It did not receive it's own keybind as it would need to be bound by default and we already use a lot of the number keys for FPS weapons, removing friction from the default experience is important
The key goal here was to ensure that pulling something out in a combat situation is consistent as having to open a wheel to select something consistently as part of removing 'jank'
It also provides an intentional choice people have to make between a pistol or the medgun which is an important trade off
as we move further into specialisations with armours (as seen with things like combat visors), you will have to make active choices about your loadout, having to choose some utility over others

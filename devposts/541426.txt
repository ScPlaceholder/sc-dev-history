Yes you will have to do a fresh install essentially because the delta patcher uses a particular format to track changes across builds, which the old version of the game doesn't use. However, subsequent updates after that will be incremental. The delta patcher is awesome, and has considerably improved our dev experience in house. We went from getting new builds in 30 minutes upwards to an hour (when it was acting up) with lots of crashing to the new system that is so fast that sometimes I forget if I ran it and I run it a second time just to be sure.

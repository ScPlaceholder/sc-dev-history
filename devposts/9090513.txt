## Features & Updates
Added New Ship: Kruger S65 Stingray
The Kruger S65 Stingray is now available in the Persistent Universe
If you've already put substantial time into testing the PTU, you may find the Stingray available immediately with today's new build. If you're just getting started with the PTU today, you can earn access by completing 3 Cargo Missions, completing Siege of Orison, or completing a Recco Battaglia Story Mission.
Access will be granted manually this time, so it may take some time to show up after you've completed one of the activities above. If you've done one of them and don't see the Stingray right away, give it some time and check back later.
For more information about the stress test and stingray, check out this post here!
https://robertsspaceindustries.com/spectrum/community/SC/forum/1/thread/ptu-stress-test-siege-of-orison-recco-battaglia-an
Experimental VR Updates
Water simulation and caustics now render correctly in VR, with the screen-space wobble effect reworked to be wave gradient based so it renders consistently in both eyes
Fixed underwater sun shadow banding and artifacts in VR caused by missing per-pixel dithering
Fixed hardware mouse cursor remaining hidden after navigating UI with a gamepad or D-Pad

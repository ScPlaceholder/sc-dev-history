GPU-side culling can be nicer (you get to use fresher data) but means you can't cut work on CPU based on the result. For instance, with the CPU system we can avoid submitting shadow calculations for lights that aren't visible. Modern APIs like Vulkan add some flexible features that help with GPU-driven command-generation, but fully switching to GPU culling would mean moving a lot of stuff we currently do on CPU to the GPU just so that we'd be able to skip the culled ones. I probably shouldn't try to give any more detail than that because it's not my special area.
Worth mentioning though that we also do frustum and portal culling on the CPU, so it's not like we'd be cull-less if we had GPU-only occlusion culling. In the end it all comes down to trade-offs.

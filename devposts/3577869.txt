Specifically concerning the mining arm we have some improvements coming up for 3.12 (that is if the QA doesn't find any issues with the changes):
- VJoy controls to all ground vehicles
- Adds a function to "freeze" any gimbal / mining arm in place (RALT-G)
- Adds function to freeze the rotation on wheeled vehicles (RShift ... like in ships)
Theoretically we could implement a specific aiming axis for mining arms. We actually had that in the past and caused a lot of headaches in the input system. Nowadays we could implement it in a different more robust way but I really would like to wait until we get the first 3.12 feedback.

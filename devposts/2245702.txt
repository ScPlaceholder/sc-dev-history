## Star Citizen Patch 3.6.0o
Alpha Patch 3.6.0o has been released to PTU and is now available to test!  Patch should now show: PTU-214814.
It is strongly recommended that players delete their USER folder for the Public client after patching, particularly if you start encountering any odd character graphical issues or crash on loading. The USER folder can be found (in default installations) at C:\Program Files\Roberts Space Industries\StarCitizen\PTU.
Please monitor sc-testing-chat in spectrum for updates and testing instructions.
UPDATED USER.cfg settings:
r_displaySessionInfo = 1
The new setting will display a QR code that we can use to track down server information when looking at your bug reports and videos.  Then can be disabled by setting it to "0".
Testing Focus
- Law and Criminality System
- Weapon optics
- Ship component degradation
- Ship combat balance: Ship shields, missile damage, missile counter-measuring
- Flight: Hover mode, acceleration control
- Head tracking
- P-72 Archimedes
- Hacking gameplay
- Pip accuracy and ship flight jitter
- Vanguard Warden and Hoplite
Known Issues
- Dropping the hacking chip on planetary surfaces can cause it to fall through.
- Entering a no fly zone while in hover mode will cause the ship to get stuck.
- Significant first person framerate reduction can occur.
- Textures will display across the visor on some helmets.
- Escort NPC ships fly in a circle and never reach destination.
- Players have to accept/reset the character customizer at each game entry.
- Ship HUD doesn't properly update landing gear.
- The cargo lift elevator of the Reclaimer may move the wrong direction.
- AI ships have an unintended wing wobble behavior.
- NPC beacons are sometimes unable to find a safe spawning position and fail to generate.
- Global proximity chat sometimes doesn't work when first logging in or returning from a direct call.
## Feature Updates
Missions
- If a player disconnects while holding a mission item, they will now drop it.
FPS
- Lowered the damage of the KSAR Scalpel.
Ships and Vehicles
- Various material color updates for the Vanguard.
## Bug Fixes
- Fixed an issue where players would be unable to buy multiple commodities at once.
- Players should now be able to purchase optics directly from the shelf.
- Mission spawned AI ships should now correctly acquire targets and not twitch when out of range.
- Flared out Terrapin's front thrusters slightly so they don't intersect when not in VTOL.
- VOIP audio widget should no longer be overlapped by the chat interface.
- Scanning a ship filled with cargo should now provide the player with more complete information.
- Fixed an issue that pushed the player off of the elevator when attempting to enter the Constellation from EVA.
- Fixed a bug causing delivery boxes to be storable in character pockets.
- Security ships should no longer be displayed with hostile/pirate colors.
- Fixed the counter hack mission spam and updated mission info.
- AI security ships should no longer spawn behind the player during scan interdiction.
Technical
- Fixed 2 server crashes.
- Fixed 3 client crashes.

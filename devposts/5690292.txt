the current armor values are just functional place holders as is the current armor implementation itself ...it just acts as a flat damage modifier and it does not degrade in any way as it is planned for the physicalized armor system.
So if you see a modifier value of 1 it means no damage reduction is applied by the armor (damage is multiplied by 1). If you see a 0.5 it means that 50% of the damage are scrubbed off. So if you see Drake ships with a higher number than other ships it is actually correct this way.
I know there is a bit of unrest concerning the armor and shield penetrations values but the current values get us a bit closer to the intended design without having the actual armor system in place. We are considering a stop-gap solutions for deeper armor gameplay until the full physicalized armor system is in place. But how we progress here (i.e. if we go for a temporary stop gap solution or not) depends on how playable the game is until then. So please keep playing the 3.18. PTU, the more data we have the more educated choices we can do.
PS: Erkul is a great tool to skim through game data (and fankly often enough pointed us out where we forgot to set certain values :grimacing: ). However be careful how you use it and pay attention to which values actually relate to the game dynamics, especially since we also have a lot of old or deprecated data floating around. In the end actual playtesting and feeling is more valuable feedback than calculating TTKs, etc. from raw data.

As we've done the last year or so of patch cycles, we only show the next patch cycle on Release View once those items have been given their QA Test Requests. This usually occurs after the previous patch is out or very close to it (think all-waves PTU). We could definitely start putting cards into a new column now, but currently that runs a higher risk of things being added and then removed, which is something we have been trying to avoid since we made changes to Release View in 2022.

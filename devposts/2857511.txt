We are very aware of the limitations of the input system. Within the dev team we have a lot of HOTAS users (myself included) which are affected just as much as all players, so we absolutely understand that. The actual issue here is not that we do not want to change the input system ... we simply lack the resources (that means dev time) to work on this in the short term.
So all we can do atm is to offer a couple of band aids where it obviously affects the experience. In the long term we absolutely want the controls & bindings screen to be so flexible that any 3rd party software is obsolete.

Hello everyone,
Today, we are excited to share the RSI Launcher 2.1.0 with everyone.
RSI Launcher 2.1.0 can be found here:
https://install.robertsspaceindustries.com/rel/2/RSI%20Launcher-Setup-2.1.0.exe
This version is focused on optimizing GPU/CPU performances and fixing video background issues.
## :wrench: Fixed Issues:
- LCH-190-743-835 – Video in the background become stuck.
- LCH-204 – Very high GPU/CPU usage when open.
- LCH-818-867 – Sign-In button is hidden with a specific screen resolution.
- Fixed – user can go back and forward like a browser.
- LCH-399 – Infinite queue when not agreeing to the disclaimer
- LCH-1167/1158/1154 – User are blocked in Login Loop
- Updated – Cards are scrollable with mouse
- Update the message on game crashes with the game error code
- Fixed SC logo disapreared on accesibility mode
## :bug: Known issues:
- Some users encounter a flickering Launcher background, which can be partially mitigated by turning off accessibility settings. Please look at this comment for a potential fix: https://robertsspaceindustries.com/spectrum/community/SC/forum/1/thread/rsi-launcher-2-0-6-release-notes/7279512
- LCH-661: 3001/3005 error may arise during the Base P4K download. Please verify or delete your game and restart download to resolve this issue.
- The Launcher sometimes fails to create the StarCitizen/Live folders for some users, leading to Error 2000, Error 5008, or Error 5010. Try creating the folder manually and running the Launcher as an administrator.
- LCH-1030: Launcher suppresses Screen Saver
Give these features a try and share your thoughts with us! Your feedback is essential for improving the Launcher.

## Release View
## 4.3.2
All 4.3.2 cards were marked as Released. Some notable additions:
Assault Rifle "Killshot"
Featuring both a ballistic and energy projectile, this rifle fires each in tandem giving you the best of both worlds with a competitive magazine size, high damage and a punchy aim profile.
:scroll: This card has been set to Released.
LMG "Pulverizer"
This LMG features a massive drum mag firing 50.cal rounds down range at targets, hitting as hard as it looks with a low RPM and deadly damage. It uses the same profile as the recent VOLT LMG, allowing you to fire at targets from longer distances.
:scroll: This card has been set to Released.
Blade "VCK-1"
These Vanduul-inspired knives are a new melee weapon using the classic melee mechanics, but with a deadly alien twist.
:scroll: This card has been set to Released.
Anvil Paladin
Introducing Anvil Aerospace’s latest gunship: the Paladin.
:scroll: This card has been set to Released.
Esperia Stinger
Implementing Esperia's latest Vanduul replica, the Heavy Fighter Stinger.
:scroll: This card has been set to Released.
Grey's Market Shiv
Implementing Grey's Market's first ship to the 'verse: the Shiv.
:scroll: This card has been set to Released.
Mission Pickup on Location
Enabling new missions to be discovered and added to journals when you approach or enter a designated area. This is first being introduced to Wikelo's Imperium.
:scroll: This card has been set to Released.
Monocular Range Finders
The Monocular Range Finders make surveying the battlefield easier, with a 10x zoom to spot hostiles at distance and light amplification providing greater night visibility.
:scroll: This card has been set to Released.
## 4.4.0
New Wikelo Ships Offerings (4.4.0)
Adding multiple new vehicles and equipment to the ever-expanding Wikelo's Emporium: RSI Meteor and the Guardian MX, with upgraded components and a unique base livery. These rewards can be unlocked by completing Wikelo's contracts.
:scroll: This card has been set to Tentative.
Shotgun Pistol "TripleDown"
Bolt action, mag drum, triple barrel and a buckshot pistol.
:scroll: This card has been set to Tentative.
Missile Launcher "Boomtube"
Three rockets strapped together in a tube releasing a single deadly payload. This weapon has high spread and an arming distance leaning into its chaotic unpredictable nature of finding the sweet spot distance.
:scroll: This card has been set to Tentative.
Interstellar Hauling Missions
Implementing hauling missions that start in one system and finish in another.
:scroll: This card has been set to Tentative.
Exterior Freight Elevators
Adding new ways of loading and unloading cargo in Nyx and Pyro.
:scroll: This card has been set to Tentative.
Nyx Missions (Pack 1)
Adding a first pack of missions to Nyx, using existing archetypes with a fresh new narrative spin against new enemies.
:scroll: This card has been set to Tentative.
Nyx Jump Points
Introducing jump points between Nyx and Pyro, and between Nyx and Stanton.
:scroll: This card has been set to Tentative.
Vanduul NPC Pilots
The Stinger, Glaive, Scythe, and Blade make an appearance as NPC ships flown by Vanduul.
:scroll: This card has been set to Tentative.
Sworn Enemies
Implementing a new operation welcoming players to Nyx. InterSec is looking for contractors willing to investigate abandoned QV Logistics stations to follow the trail of Vanduul tech that was sold to ASD.
:scroll: This card has been set to Tentative.
Nyx System
Implementing the Nyx star system into the persistent universe.
:scroll: This card has been set to Tentative.
Glaciem Ring
Implementing the Glaciem Ring, a dense asteroid belt located in the Nyx system.
:scroll: This card has been set to Tentative.
Delamar
Implementing Delamar, an inhabited asteroid in the Nyx system, home to the settlement of Levski.
:scroll: This card has been set to Tentative.
Levski
Implementing Levski, a settlement on the asteroid Delamar in the Nyx system.
:scroll: This card has been set to Tentative.
QV Services Stations
Implementing abandoned QV Stations across Nyx, some now occupied by a new enemy faction.
:scroll: This card has been set to Tentative.
Medium Battle Tech Armor
Adding a new Medium Battle Tech Armor.
:scroll: This card has been set to Tentative.
Wikelo Medium Battle Tech Armor
Adding a new Wikelo Medium Battle Tech Armor that players can obtain by completing the corresponding mission from Wikelo's Emporium.
:scroll: This card has been set to Tentative.
New Hairstyles (4.4.0)
Adding one additional hairstyle, and eleven new facial hair customization for your character.
:scroll: This card has been set to Tentative.

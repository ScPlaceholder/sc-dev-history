## Star Citizen Patch 3.5.0g
Alpha Patch 3.5.0g has been released to PTU, and is now available to test!  Patch should now show: PTU-1309067.
It is strongly recommended that players delete their USER folder for the Public client after patching, particularly if you start encountering any odd character graphical issues or crash on loading. The USER folder can be found (in default installations) at C:\Program Files\Roberts Space Industries\StarCitizenPTU\LIVE.
Please monitor ptu test chat in spectrum for updates and testing instructions.
USER.cfg settings:
r_displayinfo = 3
Note: This patch does not contain all of the intended features, which will be added iteratively to the notes as they become available. Additionally, some features may be implemented in a partial state and as such are not ready for testing.  When those features reach a playable state they will be detailed on the notes and added to the "Testing Focus".
Testing Focus
- IFCS: Heat Rework, Atmospheric flight, Arena Commander
- Balance: Manual gimbals, auto-convergence, cannons vs repeaters vs scatterguns, ship roles
- Locations: ArcCorp, Area18, Lyria, Wala
- Star Marine: All game modes
- Female Character
- DNA face customization system
- 300i
Major Known Issues:
- Ships spawned via ASOP Terminals in Area18 will be destroyed immediately.
- Some parts of Area18 have an invisible no-fly zone that will kill the player.
- Female characters are missing their visor UI.
- Some aspect ratios do not work well with the ship HUD.
## Feature Updates
Universe
- Polish to building placement and geometry at Area18.
- Further polish to Area18 advertisements.
- Updated new stash houses with trading kiosks.
- Added ambient audio to Area18 hab tower.
- Dimmed the sky bus lights at Area18 slightly.
Ships and Vehicles
- Added the updated 300i.
- Implemented new turret HUD on the Hurricane and Cutlass.
## Bug Fixes
- Players should now consistently spawn at the correctly location when they land at major landing zones.
- AI ships should no longer be killed by the no-fly zone.
- ATC should now consistently assign the player a hangar at Area18.
- Players should no longer get stuck in an endless blood loss loop if they die at Area18.
- Using the scroll bar in eidonomy will no longer rotate the head.
- Mission objectives should no longer be missing from the player's HUD.
Technical
- Fixed 2 client crashes.
- Fixed a server crash.

So, first, I want to clarify that what we have is basically a reaction control system.  That's a much simpler system than an aerodynamic FBW system, definitely.  So there is no control law related to aerodynamic conditions (drag, lift, gravity).  The system functions in either a velocity or positional control mode, with a PID-like feedback loop providing error correction toward the set state on each control axis.
One of the important things to realize is that we don't have any aircraft in the game.  We have spacecraft which can be flown in atmosphere.  We attempt to accurately model the forces from drag and lift that will apply to any ship based on its structure and characteristics of motion, but these ships do not fly by control surfaces.
What you've shown here is interesting.  If you could provide some links or reference materials, I'd like to learn more about it and consider if there is any way to use it with our systems.  I currently employ a feed-forward control algorithm that describes the goal flight behavior of a vehicle (the 3rd order motion profile that we use), plus a feedback loop to correct for errors between a ship's actual motion and the intended motion.  Perhaps what you've presented could be used as a modifier to the feedforward motion for atmospheric control.  But I would need to understand it better to say for sure.

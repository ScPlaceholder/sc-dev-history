There are continuing updates to the matrix data set as the CIG ship stats team read comments and double check the data.
The matrix data comes entirely from a CIG design database and is  automatically loaded up through a series of programs in a data model for display on the matrix and link to the store items, variant comparison tools, etc. This toolchain can obviously also update the stats from the source when new revisions are made.
Once loaded, editing tools allow to modify or add  to the specifications for each ship. (for example, holoviewer models, points of interest, etc). This is where more information is added to correlate the stats.
At this time the CIG/design source database cannot model every aspect of the ships/components (that's not how the design teams approach this work) and so a certain number of  component specifications must be added after the fact from other sources. Every ship/vehicle spec sheet is versioned and tracked in a publication flow for release in the live matrix. (for handling cases of re-design of an entire ship for example).
As for a changelog on those updates, I'll ask the cig stats team if they could log all of those and publish a quick post when updates are made. You'll note that the matrix now displays the update date of each ship which should also help in finding when a individual vehicle has been updated.
Hopefully this is useful info!

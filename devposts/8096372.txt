Phantom inputs are a problem of the sticks, not of SC. If you don't reach the axis position reliably then recalibrate your sticks. That can be necessary e.g. when you didn't use them for a long time of have them stored in a position where the axes are not at rest, especially when they are powered on.
For calibration always use whatever tools come with the sticks themselves. If you Virpil, use the VPC tools, if you ues VKB use theirs. They have fantastic tools allowing you to do a ton of things, including setting up better deadzones, etc.
Only use the Windows calibration if there is no software available.

That behaviour is somewhat expected, Star Citizen only applies the input from the last used device. So if you press e.g. W on the keyboard and thrusting forward via a throttle both inputs will point to the same ingame function (thrust FB axis) ... so only the latest one is actually use for the input. That makes it e.g. possible to hot swap e.g. from HOTAS to MKB.
It is not ideal but changing that behaviour would require a bigger refactor of the input system.

We've had discussions about populating these planets too with the tool, but they're a bit more tricky so not a priority first.
These planets don't use the usual planetary data as other planets.
Let's take Crusader for example, the actual "planet" here is the core of Crusader, so the tool currently would place locations on that, rather than in the clouds above, so we would need to support placing objects high above in the clouds and taking the planetary curvature into account when offsetting.
TL:DR, it's not our priority as populating regular planets is the first aim of the tool since those are more common :slightly_smiling_face:

I'll add my two cents as well as a gameplay programmer.  A big part of my contribution to 3.0 is helping the team push several persistence related features such as Cargo, Inventory, Entity Owner Manager, Repair, Shops, and more. As we're developing these features we're also developing our technology with how we interface with the persistent database. Between major releases we're likely going to be making large API breaking changes that will invalidate persistent data even if it were kept around. This in combination with the inevitable bugs will come up means that I think this kind of wiping will need to be happening until development of persistence related features stabilizes.

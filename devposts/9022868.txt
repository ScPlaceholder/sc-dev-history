## Features & Updates
ASOP Terminal
Updates to ASOP terminal code to help ships that are currently spawning in transit to a pad to now correctly suppress the claim button, preventing a false claimable state during delivery. Further update have also been done to make it so the terminal can now correctly query vehicles stored in hangar inventory, preventing incorrect "Claim only" status on stored ships
Valakar Behavior Updates
Updates to Valakar behaviors have been made to further distinguish types as well as fix issues previously encountered. Sentry Valakkars will not Bite and will instead hide if you get too close. Mobile Valakkars will move in combat to chase you down or reposition. Juvenile Valakkars now have a Bite Attack. Ensured that Valakkars always have a purpose in being above ground (reduces idle wiggling). Fixed bugs with some Valakkar attacks not doing damage.
Additional Updates
- Grenade HUD Markers: Live grenades will now display a warning marker on the HUD
- Hit Markers: Hit marker visuals have been updated to thinner markers and flat crosshairs for a cleaner look
- Bombing Run Missions: Bombing Run missions are now regional and will only appear in the area of space where the mission takes place, rather than being visible system-wide

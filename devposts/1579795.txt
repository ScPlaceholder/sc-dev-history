generating the extra geometry is not necessarily the issue in this case. we would need to deform that geometry with textures and for that we need mapping coordinates. (tri-planar projection unfortunately does not work very well for continous spherical surfaces if you want any kind of directionality in your textures). right now we are projecting the textures top-down (relatively speaking...).
assuming there is a feasible way to map those vertical surfaces (remember that there could be a single connected cliff going in squiggly lines over the entire planet, so any solution needs to be able to cover this or even something a fraction of that as well) then this would also need to happen on the server for collision purposes.

## Features & Updates
New In-System Event
A new event has arrived in the Stanton system. Head to Stanton and check your mobiGlas contract manager to find the available contracts. The event includes a dedicated mobiGlas tab, a progress tracking UI, a journal entry, and a reward track.
VR Feature Test
- VR is now enabled automatically when turned on in the Launcher. Previously it also had to be enabled separately in the in-game menu, which caused confusion
- New VR zoom implemented for F-key interaction, precision targeting in ships, and FPS weapon ADS and scopes. A new option, Zoom Gameplay Strength, has been added to reduce the effect or disable it entirely when set to 0. Precision targeting now temporarily snaps the view to the target and significantly reduces look rotation to stabilize the view and reduce nausea
- GroundedLook mode now correctly uses the aim vector for hand mining and similar activities
- In Freelook mode, tractor beam aiming can now be controlled with head movement, allowing the same speed of use in the ATLS in VR as on desktop
Shield Resistance
Shield resistance values now function correctly when minimum and maximum resistance are set to the same value; previously the restriction that minimum must be lower than maximum caused resistance to be ignored entirely
Abandoned Ship Cleanup
Vehicle lifetime overrides extended to Everus Harbor, Seraphim Station, Bajini Point, and Port Tressler, improving cleanup of abandoned ships at these locations
Character Customizer
Brow dye opacity slider now defaults to 0, matching the behavior of the hair and beard sliders

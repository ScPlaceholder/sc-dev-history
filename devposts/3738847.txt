That is referring to occasions where a bug is reported by the community but we can't reproduce it internally and can't track it down without more information. In code it may look as though one of a few supposedly impossible things must have happened to cause the bug. If the issue is serious enough then to help us identify which "impossible" thing is causing the issue a programmer may need to add some code saying "if impossible thing X happens then crash here." It's a drastic option and therefore one we like to avoid but is a very effective way to very quickly get useful information about a serious issue we're otherwise struggling with.
To be clear though, this technique is only used rarely on PTU when the issue is serious enough that it would prevent the patch going Live.

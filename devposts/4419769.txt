"The second part of the message recommends creating or contributing to a report that is updated to the latest version if the issue persists."
- This quote is taken from a direct response of mine to a player who has left feedback about the fact their report was Archived, hence it lacks the full context here.
If a report is Archived, it is impossible to add contributions to it, so in that scenario the only way indicate that the issue is ongoing is to create a new report. We do not consider that creating a duplicate in that case as Archived reports are not actively reviewed. If there are no reports in the Open, Confirmed or Under Investigation state and the issue persists, absolutely feel free to create a new report.
I can understand the confusion and it's something we're actively working on streamlining. For a start, we want to de-emphasize Archived reports in the duplicate check tool in the future, showing them only if no other reports match to give the player context about similar reports that have been Archived previously. Your suggestion about a "Best Practice" document is duly noted.

Other than that when the label says XXXX TOGGLE / HOLD, it is usually a combined binding ... that means if you hold it for 0.25s it will count as a hold ... if you release before that it will toggle.
In other cases where it says XXXX HOLD it means you need to hold the button down for the action to activate (meaning a state swaps as long as you hold the button down). If it says XXXX TOGGLE it means the action only toggles the state (e.g. swaps coupled on and coupled off).
So basically the labels should tell how you need to use that binding. Same for buttons that say long press or short press.

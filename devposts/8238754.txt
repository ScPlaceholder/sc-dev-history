Hi. I've mentioned elsewhere that we haven't looked at FSR4 yet because it only supports Vulkan (+DX12) so would likely require us to drop FSR completely from DX11. So while we're actively testing Vulkan as the default renderer in Evocati right now, we're still a bit away from it becoming the default in the main live release and also being confident enough to fully kill off DX11. So we'll need to wait just a little longer for FSR4. It's perhaps worth mentioning that CIG's TSR implementation beats FSR2 on quality and stability, so that should be the main option for AMD users for now.

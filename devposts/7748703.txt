If it's just the thrusters that are failing you can still glide (assuming the ship currently generates enough lift). The question is more if the flight computer / IFCS core is online or not. If offline, no commands would be moved to the control surfaces ... so you would still glide (because the aerodynamics are still calculated) but you couldn't affect the path. If the flight computer is online, you can control your ship even without thrusters being online ... landing will pretty hard though but probably not impossible.
I'll make a note to discuss that specific use case internally, I'll find it quite interesting to be able to move the control surfaces without power ... but it might not fit the lore as those fins are really large and potentially too heavy to move them with backup cables.

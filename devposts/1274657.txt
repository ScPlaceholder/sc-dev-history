" In the current flight model, there is turbulence (ships bobbing around like a boat) in the vacuum of space, in the document I noticed that this is listed as a placeholder."
Actually, turbulence is only in atmosphere, not in space.  There shouldn't be ships bobbing around like a boat.  There might be torque caused by firing thrusters that are not balanced about the center of mass, which can cause a ship to tip one direction or the other.  Like in the Mustang, as it accelerates forward, the mains set high relative to COM can cause the nose to dip down for a moment.  But that isn't turbulence.
Another possible way to have something like turbulence in space is when a ship is near a large surface of some kind.  Thrust from individual thrusters can generate turbulence when hitting a nearby surface.  You normally see this when landing on a platform, but you can also see it just by flying near to an asteroid or other ship.  But again, it's not the same as atmospheric turbulence.
BTW, it has been requested to support turbulence with ships when flying in vacuum.  The source would be from imperfect thrust.  So if IFCS requests a particular amount of thrust in order to generate a desired motion from the ship, the thrusters might generate more or less thrust, or thrust on a different vector, and as a result of this error, the actual motion might deviate from the requested motion, and then the reaction control system will kick in to correct this error.  This would read similar to atmospheric turbulence, only instead of being velocity-based, it would be acceleration-based.  The system actually already supports this, but I have been unwilling to enable it yet because I want to guarantee the system is perfectly stable before I introduce any simulated error.

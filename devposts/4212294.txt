## Thank you for over 100,000 contributions to the new Issue Council so far!
And for all your feedback and bug reports about the Issue Council. As we alluded to in the original Soft Launch Announcement, the Issue Council has continued to receive improvements post-soft launch, and this will continue, guided by your feedback.
Here is a rundown of the main changes so far:
Search - Results
- When displaying matching reports, matches in the reports' title will be heavily favored, displaying those reports near the top.
- As the entire report is checked for the search term, it is possible results will appear that do not have the search term in the title.
- The location of your search term will be displayed in the search results, with the term(s) being highlighted.
Search - Operators
The default search operator is OR, which checks for any of the terms you enter anywhere in the report. Additional search operators can now be used:
- Exact term – quotation marks: "word"
- Exclude term – hyphen: -word
- Prefix - terms with this at the start – asterisk: word*
- And – Both terms - plus symbol: word1 + word2
- Or - either term - vertical pipe: word1 | word2
- Prioritize - Like arithmetic - Parenthesis: (word1 | word2) + word3
- Variation - Similar terms - Tilde: hanger~
Search - Features
- When searching from the Dashboard, suggested issues will instantly appear in the drop down.
- Can search using (partial or full) issue code e.g., STARC-5*.
- Can search for duplicates (as determined by staff) of an issue simply by entering the issue code as an exact term with quotes, e.g., "STARC-1".
- Can search for all issues with a particular fix version by first selecting the “Fixed” status filter then searching for the CL as an exact term with quotes e.g., "7536660".
- Can combine operators.
General
- The option to allow developer contact is now presented during the report creation process, if the option is not already enabled.
- "Community Severity" has replaced the "Severity" field in the filters.
- Useful game-play settings can now be included during the report creation process and are saved for next time.
- Cookie preferences.
Usability
- Mobile device support.
- Dramatically reduced the required login frequency.
- Ability to log in from any page you land on without losing the page you were on.
- Maintenance screen to prevent loss of progress if adding a report or contribution while an update is being released.
- "My issue" / "My contribution" / "Followed issues" shortcuts have been moved to the left sidebar in line with other issue filters.
- The basic reason for an issue being Archived will be stated in lieu of a staff comment.
- Star Citizen is now the first project on the Issue Council homepage and wording has been changed to further distinguish the Issue Council Bugs project.
Bugfixes
- 83 bugs with the Issue Council reported by you, the players, have been fixed since the new IC was first made available. View them here: https://issue-council.robertsspaceindustries.com/projects/ISSUE-COUNCIL/issues?categories=&search=&severities=&statuses=fixed

Yes, it was an issue for some time, definitely pre 3.18. I've read so many Spectrum post about issues with not seeing bounty and delivery missions, so it had been squarely in my sights to eradicate it for some time, but now it's resolved as fixed in 3.19. We will continue to monitor ptu and live for any indication if its still about in any permutations.
A little insight as to why it was such a pain to find and fix: The bug took a lot of work and investigation by design and code to figure out. We had to keep making hypotheses for the potential cause, getting engineers to create debug that would let us test those theories (against ptu servers, as it only manifested in ptu/live) and then sift through the logs to find the potential causes.  I personally had to sift through 10s of Gigabytes of logs each time we attempted our tests in order to find the discrepancies that eventually pointed to the root cause. It wasn't all bad though because now we have some more useful debugging tools for situations like these.

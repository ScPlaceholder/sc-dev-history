Hello everyone,
Today, we are releasing the RSI Launcher 2.19.1.
RSI Launcher can be found here:
https://install.robertsspaceindustries.com/rel/2/RSI%20Launcher-Setup-2.19.1.exe
In this version, we’ve updated the display of the download process to better indicate the status of the download phases and how many remain.
We’ve also added a shader compiling stage, so that this task can be done before entering the game.
The shader compiling feature is only fully working with game version 4.10.3 and up. Until then the game might still complie shaders while getting in the game.
## :gear: New features:
What's new in this release:
- New downloads panel: the header popover now shows the ongoing installation (version/channel, step-by-step progress, pause/resume/cancel, network, disk, CPU and memory usage).
- The game page also shows a compact step row and progress bar under the game button.
- Shader compilation (optional step): at the end of an install or update, the game can now compile its shader cache before entering the game. You can launch the game at any time, or choose “Skip shader compilation”: the install completes and the game finishes its shaders on the next launch.
- New Settings for deleting and compiling shaders from the games settings.
- The compiling phase can take from 7 to 30+ min depending on your computer.
- Updated data patcher for data generations: smoother progress reporting, a verification pass that repeats until the files are clean, more detailed error information, and a dedicated dialog when the disk fills up during a download.
- Guide System: Presence status in the account panel and in the guide session is in sync with the web
## :wrench: Fixed Issues:
- Downloads panel only redraws the values that change, reducing UI load during installs.
- Fixed the Launcher muting and minimizing before showing the “already running” message on a double click launch.
## :bug: Known issues:
- If you witness a black rectangle on the bottom right of your screen, please turn off the overlay notification in your notification settings.
- Some users encounter a flickering Launcher background, which can be partially mitigated by turning off accessibility settings. Please refer to this comment for a potential fix: https://robertsspaceindustries.com/spectrum/community/SC/forum/1/thread/rsi-launcher-2-0-6-release-notes/7279512
- The Launcher sometimes fails to create the StarCitizen/Live folders for some users, leading to Error 2000, Error 5008, or Error 5010. Try creating the folder manually and running the Launcher as an administrator.
- LCH-1030: Launcher suppresses Screen Saver
- LCH-1958: Never Ending Download loop. Please report the issue; we're having trouble reproducing it.
- Users might encounter Desync with Language and Proficiencies while using the guide system both on Spectrum and in the Launcher at the same time.
- For game version lower than 4.10.3 complile shader might be run a second time when getting in the game. This is fixed for game version 4.10.3 and up.
Please try this version and share your feedback with us! Your feedback is essential for improving the Launcher.

Frame pacing is a hugely complex topic, so I wont dive too deep here in this thread.
But it’s highly subjective, and we can’t please everyone. For many, 50fps on a 60Hz monitor feels juddery, because the game can’t predict which frames will take too long, so they’re all simulated as the same amount of time. This is a problem because while an object may be moving N meters per T milliseconds, on the frame that is “dropped” the object will move N meters in 2T milliseconds (because we see this frame twice), ie it’ll temporally be half the speed. So for many, 30fps is preferable when dropping below 60fps. Of course it’s much better to have a higher refresh display and also freesync, as then you can achieve smooth framerates beyond just 30 and 60.
It’s also worth mentioning that we measure the previous frame time, and intentionally smooth the frame rate over time, so we shouldn’t bounce between 60 and 30 too frequently.

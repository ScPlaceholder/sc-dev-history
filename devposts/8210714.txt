Automating things ( such as stowing a shard ) that directly interface with the database is dangerous. We have to ask the question: is it worth the amount of time it would take to safely automate this or should we let an admin handle it?
Sometimes when we stow a shard that is crashing like this, it doesn't crash when it starts back up. However, sometimes it does. That means that if we automated this, we could potentially have a shard that is starting up, loading information from the database, crash, stow again, and then keep repeating this. Automating this also makes it possible for this to be happening with more than one server at a time which would compound the database load.
There's two effects this has. One, it increases load on the database, which is something we definitely want to avoid. Two, it makes the crashes slower. Crashes happening less often makes the issue less 'observable'. It's easier for something to be mistakenly given a lower priority if it isn't happening all that often.

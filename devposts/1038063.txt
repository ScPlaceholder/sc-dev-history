## Star Citizen Patch 3.1.0o
Alpha Patch 3.1.0o has been released to the PTU, and is now available to test!  Patch should now show: PTU-7388857
NOTE: Please copy your account to PTU for this patch.
It is strongly recommended that players delete their USER folder for the Public client after patching, particularly if you start encountering any odd character graphical issues or crash on loading. The USER folder can be found (in default installations) at C:\Program Files\Roberts Space Industries\StarCitizenPTU\LIVE.
New Known Issues:
We have an attempted fix for the graphical corruption bug, but if it persists we would like to collection some information from you directly. Note how long your play sessions are and let us know if you encountered the issue or not in the following short survey: https://goo.gl/forms/6q7owepvl8a6xwtX2

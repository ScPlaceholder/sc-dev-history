## Star Citizen Patch 3.3.0ab
Alpha Patch 3.3.0ab has been released to the PTU, and is now available to test!  Patch should now show: PTU-984109.
It is strongly recommended that players delete their USER folder for the Public client after patching, particularly if you start encountering any odd character graphical issues or crash on loading. The USER folder can be found (in default installations) at C:\Program Files\Roberts Space Industries\StarCitizenPTU\LIVE.
Please monitor ptu test chat in spectrum for updates and testing instructions.
USER.cfg settings:
r_displayinfo = 3
Note: This patch does not contain all of the intended features, which will be added iteratively to the notes as they become available. Additionally, some features may be implemented in a partial state and as such are not ready for testing.  When those features reach a playable state they will be detailed on the notes and added to the "Testing Focus".
Testing Focus
- Teach's Ship Shop
- Missions: FPS combat mission and scramble races
- New Ships and Vehicles: Valkyrie, Phoenix, Hammerhead, Mustangs, and Cyclones
- Manned and remote turrets
- Changes to ship cannons
Major Known Issues:
- VOIP/FOIP are not functioning properly.
- Mission markers no longer appear after using crash recovery.
## Feature Updates
UI
- Removed ship selection from kiosks and setup item preview as main 3D window.
- Replaced infopane preview window with manufacturer logo on kiosks.
Arena Commander
- Changed REC rewards for Arena Commander to better match ship rental prices.
- Rented ships are temporarily not able to be edited.
## Bug Fixes
- Recco Battaglia should now function properly.
- Interdictions should once again be occurring.
- Players should no longer randomly spawn at Levski.
- Players should be able to accept and receive other service beacons after declining one.
- Ships should no longer despawn from Teach's Ship Shop.
- Ships purchased at Teach's Ship Shop should now have insurance.
- Fixed wild camera rotation on comm calls.
Technical
- Fixed 4 server crashes.
- Fixed 7 client crashes.
- Fixed a server deadlock.

Spectrum Alpha 0.3.1
These are the patch notes for Spectrum 0.3.1. Please make sure you reload your client to see the benefits!
New Features
Added permalinks on forum replies
Added "new replies" indicator inside forum channels
Added bookmark widget on each lobbies & categories in community index
Improvements
Improved threads list readability: Added thread creation time
Improved threads list readability: Subjects are bigger and extra info is faded when not hovered
Reactions are now capped to a limit of 6,  until expanded
Roles set to invisible can now be used to highlight chat messages & thread posts
- settings descriptions added to make things clearer
Highlight role selector for thread replies now remembers the most recent choice
Newly created threads and replies are now automatically upvoted for you
Improved notifications panel: Automatically read all notifications on panel close, added "Remove all" button
Bug Fixes
Fixed issue where default community redirect would redirect to invalid url "/community/Map%20%7B%20"SC":%20"1",%20"MYORG":%20"2"%20%7D"
Fixed issue where it was not possible to create thread with russian/chinese characters
Fixed issue when loading a chat lobby without permission it would make the page crash
Fixed +1 emoji not being suggested/rendered, thumbs up for everyone!
Fixed bug preventing collapsed forum replies from being expanded
Fixed role highlight selection not supporting multiple members on the same computer
Fixed latest thread reply sometimes being highlighted with wrong role in Channel page
Fixed forum thread emoji picker appearing under the replies
Fixed crash when removing media existing message
Fixed a bug where a vote on a reply would report the thread vote count in the notification
Fixed a bug where twitch replay videos were offset in media embeds
Fixed chat lobby user list defaulting to visible on mobile
Fixed mention with special characters not being detected
Fixed a bug where invalid forum channels specified in the URL would cause an application error.
Fixed a minor bug in Search results for some malformed threads.
Fixed missing background when user avatar is transparent png in Member profile popup
Fixed bug where threads or replies count was out of date

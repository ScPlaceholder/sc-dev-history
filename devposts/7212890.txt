Hello everyone,
Today, we are excited to share the RSI Launcher 2.0.5 with everyone.
RSI Launcher 2.0.5 can be found here:
https://install.robertsspaceindustries.com/rel/2/RSI%20Launcher-Setup-2.0.5.exe
The primary aim of this version is to introduce the Offline feature. This advancement allows the RSI Launcher to manage authentication more effectively when there's a network disruption or the computer enters sleep mode. This has been a significant concern highlighted by reporters on IC. Additionally, we have addressed issues related to the size of the sign-in window and enhanced the flexibility of the download speed feature. Users can now manually set the download speed limit in KB/s.
## :hammer_and_wrench: New feature:
- Offline Mode
- Manually set your download speed limit
## :wrench: Fixed Issues:
- LCH-36 – IP Change error (2.04)
- LCH-48 – Launcher fails to recover when started offline (2.04)
- LCH-97 and LCH-814 – Session expiration prompts for password twice (2.04)
- LCH-339 – Request for a more detailed download speed limit setting (2.04)
- LCH-690 – Frequent logout from the Launcher  (2.04)
- LCH-948 – Install error 1013 Could not retrieve agreement from server (2.0.5)
## :bug: Known issues:
- Some users encounter a flickering Launcher background, which can be partially mitigated by turning off accessibility settings.
- A 3001/3005 error may arise during the Base P4K download. Please verify settings to resolve this issue.
- The Launcher sometimes fails to create the StarCitizen/Live folders for some users, leading to Error 2000, Error 5008, or Error 5010. Try creating the folder manually and running the Launcher as an administrator.
- High CPU usage has been observed when the background video is playing.
Give these features a try and share your thoughts with us! Your feedback is essential for improving the Launcher.

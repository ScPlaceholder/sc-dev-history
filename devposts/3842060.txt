There are a lot of causes for this error so there isn't any one solution. Statistically speaking, a good deal of what causes this error are server crashes or deadlocks, however 15-30 minutes is much higher than the current average. Last time I checked, I think the average was about 8 hours of gameplay before someone runs into a server crash ( due to how averages work though, there will be some people that are going to run into them sooner than that ). That means either you're really good at crashing game servers ( which is possible. There may be something you're doing that is causing them) , or something is potentially causing a connectivity issue between the game client and the game server.

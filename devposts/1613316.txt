## Star Citizen Patch 3.3.0y
Alpha Patch 3.3.0y has been released to the PTU, and is now available to test!  Patch should now show: PTU-979539.
It is strongly recommended that players delete their USER folder for the Public client after patching, particularly if you start encountering any odd character graphical issues or crash on loading. The USER folder can be found (in default installations) at C:\Program Files\Roberts Space Industries\StarCitizenPTU\LIVE.
Please monitor ptu test chat in spectrum for updates and testing instructions.
USER.cfg settings:
r_displayinfo = 3
Note: This patch does not contain all of the intended features, which will be added iteratively to the notes as they become available. Additionally, some features may be implemented in a partial state and as such are not ready for testing.  When those features reach a playable state they will be detailed on the notes and added to the "Testing Focus".
Testing Focus
- Teach's Ship Shop
- VOIP and FOIP
- Missions: FPS combat mission and scramble races
- New Ships and Vehicles: Valkyrie, Phoenix, Hammerhead, Mustangs, and Cyclones
- Manned and remote turrets
- Changes to ship cannons
Major Known Issues:
- Players are not put into local chat.  W/A: Open mG and click the bell icon twice, then in chat "tab" over to local.
- VOIP/FOIP mG buttons will sometimes not function correctly.
- There's an unusual "fog" on Daymar.
- Mission markers no longer appear after using crash recovery..
- There are currently no interdictions.
- Players will be locked in place, unable to move, when crash recovery is used.
- Recco is currently not functioning.
- Inviting someone to party via the mG causes a client crash. W/A: Invite via interaction mode.
## Feature Updates
Ships and Vehicles
- Increased quantum drive max range significantly and lowered the amount of fuel needed per jump.
- The Valkyrie now has thrusters able to move it forward when in VTOL landing mode.
## Bug Fixes
- Fixed an issue where players would have to restart their client to see a ship rented in-game.
- Scanning audio should now consistently play.
- Delivery lockers should now open properly.
- The shields on the Constellation Phoenix should now function properly.
- The Citizencon edition Mustang Alpha should now have proper insurance.
- Cargo containers should no longer flicker when brought aboard ships.
- NPCs around the landing area of GrimHex should no longer be stationary.
- The Valkyrie should now properly have thrusters able to move it forward when in VTOL landing mode.
- There should no longer be a collision gap in the clothing store at GrimHex where players can fall through.
- Audio for self-destruct should now be present on all ships.
- Spawned ships/vehicles should now consistently have AR location markers.
- Players should no longer be able to commandeer civilian ships.
- Fixed overly bright boundary barrier in Arena Commander.
Technical
- Fixed 5 client crashes.
- Fixed 3 server crashes.
- Fixed a Star Marine server crash.

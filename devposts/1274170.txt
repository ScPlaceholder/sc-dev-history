There are definitely issues with binary input.  For all control modes, we really expect the pilot to be able to input a level, not just the binary switch from zero to max.  So it's not very useful for acceleration mode to switch from 0 to max acceleration instantaneously, and for velocity control, obviously you don't want to fly at either zero or maximum velocity and nothing in between.  So it would be useful for keyboard input to control a level rather than toggle between two states.  So if I understand your question correctly, sure, I'd like to see more of a ramp-up rather than a toggle.  I actually implemented an IFCS input system that provided a wide range of settings for mapping input to flight control, but unfortunately it didn't make it into the game.

Using cloud providers to host servers is kinda like having the ability to create imaginary friends in your brain that can do actual work for you. There's a real physical server that using a process called virtualization to simulate a smaller server inside of it.
For those that are good with hands on learning, there are some cloud providers that have what they call 'free tier' offerings where the most basic cloud server they have is free to use under certain conditions ( which change depending on which cloud provider you're using ). It can be useful for learning but unfortunately it's also really easy to accidentally create something that has a cost associated with it. It can help to show that building a virtual machine in the cloud is pretty easy to do but the servers that are built in a cloud environment are going to just have the basic operating system that the admin building it chooses. The hard part about it ( and why we get paid to do this ) is getting the server and the rest of the cloud environment to work with the product that it's hosting, automating that process so that we don't have to manually do that for every server, monitoring it to make sure it stays running, etc.

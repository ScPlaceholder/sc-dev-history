This information is primarily for developers and PTU testing, and is part of the core engine which is completely separate from the game UI, as such there is no guarantee it won't draw on top of the game UI. We don't really want to get into an arms race where we're constantly moving the engine debug UI around to try and avoid whatever UI content might be on screen at each moment, especially when that UI changes so often (e.g. between releases, fps vs ships, UI modes, etc).
But longer term we might move the debug UI to be on floating/dockable windows, which would allow you to manage this yourself.

## Star Citizen Patch 3.3.0m
Alpha Patch 3.3.0m has been released to the PTU, and is now available to test!  Patch should now show: PTU-958784.
It is strongly recommended that players delete their USER folder for the Public client after patching, particularly if you start encountering any odd character graphical issues or crash on loading. The USER folder can be found (in default installations) at C:\Program Files\Roberts Space Industries\StarCitizenPTU\LIVE.
Please monitor ptu test chat in spectrum for updates and testing instructions.
USER.cfg settings:
r_displayinfo = 3
Note: This patch does not contain all of the intended features, which will be added iteratively to the notes as they become available. Additionally, some features may be implemented in a partial state and as such are not ready for testing.  When those features reach a playable state they will be detailed on the notes and added to the "Testing Focus".
Testing Focus
- Valkyrie
- Constellation Phoenix
- Hammerhead
- Reworked Mustangs
- Cyclone variants.
- Manned turrets.
- Changes to ship cannons.
- Power management, overpower, and overclocking ship systems and components.
Major Known Issues:
- Inviting someone to party via the mG causes a client crash. W/A: Invite via interaction mode.
- In-game chat services may not be working correctly.
- Ships rented from the front-end do not show up in ship selection list.
- Airlocks lack lighting.
- HUD vanishes when using a ground vehicle.
- Ships are able to quantum travel to locations they do not have enough fuel to reach.
- Visor chat channel does not work. W/A: Hit the "bell" icon twice.
## Feature Updates
Missions
- Re-enabled scramble race mission visor HUD.
- Updated the loadouts of Kareah FPS combat AI.
- Removed the instant rewards for killing FPS combat AI during the mission, which will now be handed out at the end of the mission.
UI
- Added a reststop model to the Starmap.
## Bug Fixes
- Fixed head snap during bed exit.
- There should no longer be a skin off-set between the head and body of the character in the customizer.
- The top part of the Valkyrie's rear door should now have collision.
- Fixed an issue where players weren't dropping pickups in Arena Commander Battle Royale.
- Races abandoned by other players should no longer be able to be accepted by others afterward.
- The Starmap should no longer take several seconds to load.
- Fixed an issue where the objective UI wouldn't vanish after objective is completed for scramble races.
Technical
- Fixed 5 client crashes.
- Fixed a server crash.

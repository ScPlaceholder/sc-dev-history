An awkward issue, though, is that you need to know what "underneath" is. In a flat-floor game, you can get away with adding a round sprite at floor height. Once you have lumpy surfaces, or multiple depths, you can maybe start adding some kind of decal volume that shades shadow on anything in the affected area, but drawing lots of these is a performance problem in its own right. We actually do do this for planets and some large objects using a sphere as the proxy shape, but each one takes several state changes and can touch a lot of pixels, so it's not something you could easily extend to large numbers of objects.

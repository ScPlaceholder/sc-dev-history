We are releasing a new PTU build with the hopes do more XenoThreat testing this weekend! This new build should show up on the PTU channel as VERSION 3.16.1-PTU.7941332
Many more fixes have gone into the build to help with many issues related to XenoThreat and we wanted to take this time with the PTU open to run another night of it to gather info and feedback!
- Fixed an issue where the Javelin could despawn if all players leave the area during its docking process which would completely break the mission
- Fixed the Javelin undocking and failing to QT away in phase 2 via completing the 2nd instance of 'Protect the  Starfarer' event on the same server
- Fixed players being unable to surpass the second iteration of the  'Protect the Javelin' event despite destroying an extortionate number of  ships.
- Fixed subsequent Idris protects so Idris should use its railgun properly
- Fixed The escort AI ships that accompany the Aegis Idris being idle and do not move to follow the Idris
- XenoThreat FPS AI should no longer sometimes spawn inside walls and potentially shoot the player through the walls
- Changed XenoThreat fps AI to use procyon hostility so they cant hurt each other

Hey there,
As we continue preparing for the launch of Squadron 42 and progressing toward Star Citizen 1.0, we’re taking the next step with a new Game Library system that gives games a clear, permanent place within each account. As part of this transition, we’re making updates to pledge gifting and game access. We’re sharing these details early so everyone knows what to expect when the changes take effect in October.
## Gifting Changes
The following changes will apply only to pledges purchased after the new gifting system takes effect in October. Existing pledges will retain their current gifting functionality.
- Pledges intended as gifts must be designated as such at the time of purchase.
- A pledge designated as a gift cannot be used by the purchaser.
- Once the recipient has received the gifted pledge, it may be upgraded normally using CCUs.
## Game Access
When the new Game Library system launches on October 1, 2026:
- One eligible pledge on each account will be designated as its primary Game Access pledge. This will be the account’s non-meltable pledge, or, if no non-meltable pledges are present, its oldest pledge.
- The primary Game Access pledge will become permanently associated with the account and cannot be melted or gifted.
- Any ships or vehicles included in the pledge may still be upgraded normally using Cross-Chassis Upgrades (CCUs).
- Additional game packages and duplicate game copies will continue to function normally and may still be gifted where eligible.
## Looking Ahead
These updates are part of the broader work underway to create a clearer and more consistent account experience for Squadron 42 and Star Citizen. We’ll share any additional information as we approach the new Game Library system’s rollout in October.

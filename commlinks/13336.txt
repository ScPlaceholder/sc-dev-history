Greetings Citizens,
We are pleased to announce that the Hangar Module patch enabling the Hornet variants is now available. Your Hangar Module will automatically download the patch the next time you connect via the launcher. This patch adds the Hornet Ghost, Hornet Tracker and Super Hornet spacecraft to the game. If you’ve pledged for any of these ships, you can now explore them! Please see this post to learn more about the Anvil Aerospace Hornet lineup.

## Weekly Wisdom: If All Else Fails
If an extremely pernicious bug has occurred that has completely hindered your ability to participate in Star Citizen Testing, AS A LAST RESORT, you can now reset your character via the account settings to refresh all of the data associated with it within our systems.
We encourage you to attempt to resolve the issues using workarounds if possible (and of course report the issues and any fixes you’ve found to the Issue Council) to avoid using this option as this process cannot be halted or reversed once started.

## Notable Changes: August 27, 2025
## Release View
## 4.3.0
All 4.3.0 cards have been set to Released: Sniper Light Armor "Geist", Wikelo Light Combat Stealth Suit, ASD Light Combat Stealth Suit, New Hair styles, Dynamic Snow, Ladder Improvements, Onyx facilities, Wikelo special ships, VOLT Sniper, L-21 Wolf
Ship Flight Tuning Changes: Light Fighters (4.3.0)
Updates on Light Fighters for the Gladius, Arrow, Hawk, Banu Defender, Talon, Blade, Khartu-Al, and Mustang. SCM & NAV speeds, accelerations, angular speeds.
- This card has been set to Released.
## 4.3.1
RSI Apollo Triage
Implementing the Apollo Triage from Roberts Space Industries.
- This card has been set to Tentative.
RSI Apollo Medivac
Implementing the Apollo Medivac from Roberts Space Industries; now with superior armor and dual missile racks for deployment on intense battlefields.
- This card has been set to Tentative.
Behring Laser Cannon Art Refactors
Updating the Behring cannons' art style and geometry.
- This card has been set to Tentative.
Onyx Facilities (4.3.1)
Update 4.3.1 expands the Onyx Facilities with the addition of the Science Wing. Arken Mallor invites players back to the network of abandoned research sites scattered across the Stanton system, hidden on nearly every moon. Though light security still lingers, the facilities have long since been abandoned by Associated Science and Development (ASD). At their deepest point lies Dr. Jorrit’s Lab, where the darkest revelations await.
- This card has been set to Tentative.
AI FPS Turrets
Adding anti-personnel turrets for players to avoid or destroy, providing additional PvE challenges.
- This card has been set to Tentative.
Mission Pickup on Location
Enabling new missions to be discovered and added to journals when you approach or enter a designated area.
- This card has been set to Tentative.

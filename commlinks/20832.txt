## Notable Changes: October 8, 2025
## Release View
## 4.3.2
Structural Salvage
Additional balancing of structural salvage as part of ongoing refining changes related to upcoming work on crafting.
- This card has been set to Tentative.
Klaus & Werner Laser Repeater Art Refactors
Updating several Klaus & Werner Laser Repeaters' art style and geometry: Size 1, 2, and 3.
- This card's visual has been updated.
New Wikelo Ships Offerings (4.3.2)
Adding multiple new ships, equipment, and vehicles to the ever-expanding Wikelo's Emporium: Crusader A2 Hercules, Crusader Ares Starfighter Inferno and Ion, Esperia Prowler Utility, with upgraded components and a unique base livery. These rewards can be unlocked by completing Wikelo's contracts.
- This card's visual has been updated.
AI FPS Turret
Adding anti-personnel turrets for players to avoid or destroy, providing additional PvE challenges.
- This card's visual has been updated.
Heavy Battle Tech Armor "Palatino"
Adding a new Heavy Battle Tech Armor.
- This card's name has been updated.
Frontier Fighters Finale
A new event in 4.3.2 related to the Fight for Pyro storyline.
- This card's name has been updated.
Mission Pickup on Location
Enabling new missions to be discovered and added to journals when you approach or enter a designated area.
- This card has been set to Tentative.
Yormandi
A large creature introduced in Alpha 4.3.2, the Yormandi lurks in the depths of the Onyx Facilities.
- This card has been set to Tentative.
Yormandi Cave
Deep within Site-B at the Onyx Facilities lies the hidden lair of the Yormandi, waiting to be uncovered.
- This card has been set to Tentative.
